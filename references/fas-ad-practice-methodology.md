# FAS Ad Practice — методология работы с рекламной практикой ФАС

Методическая база для проверки рекламных креативов на риск претензий ФАС, подготовки memo бизнесу и обоснования позиции с опорой на реальную практику антимонопольного органа. Используется skill-ом `fas-ad-practice-search` (см. `skills/fas-ad-practice-search/SKILL.md`).

**Не заменяет** юридическую экспертизу. Skill готовит **аналитический материал и черновики**, финальное решение — за юристом.

## Источник практики — FAS provider через Legal Overlay

Доступ к поисковому корпусу решений ФАС о нарушениях ФЗ «О рекламе» идёт через единую локальную MCP-точку Legal Overlay. Skill не подключается к внешнему endpoint и не собирает provider-native JSON-RPC. Технический протокол нижележащего provider — `references/fas-search-mcp-setup.md`.

**Стабильные инструменты Overlay**:
- `search_fas_ad_practice` — поиск по абстрагированному вопросу + локально применяемые filters/limit;
- `get_fas_case` — полная карточка одного дела по `docId`;
- `list_fas_filter_options` — справочник доступных годов / регионов / статей.

Каждый ответ содержит `provider_used`, attempted/succeeded providers, fallback и warnings. `DEGRADED` означает, что основной provider не ответил и gateway применил transitional fallback; это фиксируется в журнале автоматизации, но не делает поисковую карточку официальным первоисточником.

**Лимиты**: 20 req/min, 300 req/day per IP. Без авторизации.

## Когда применяется

- **Pre-flight проверка креатива** — до публикации, до запуска кампании;
- **Получен запрос ФАС** в рамках КНМ по рекламе — для подготовки ответа (вместе с `gov-response`);
- **Возбуждено дело по ст. 14.3 КоАП РФ** — для подготовки объяснений / возражений / жалоб (вместе с `procedural-document-drafter`);
- **Иск об оспаривании решения ФАС** в АС по гл. 24 АПК РФ — для обоснования позиции (вместе с `procedural-document-drafter`);
- **Memo бизнесу** по риску формулировки;
- **Критика своей позиции** перед подачей — для контр-практики (вместе с `position-critic`).

**Не применяется** для:
- Договорных споров с рекламным агентством / правообладателями элементов креатива (это `contract-review`);
- Налоговых вопросов по расходам на рекламу (это будущий tax-disputes playbook);
- Защиты ТЗ, используемых в рекламе (это `trademark-search` / `procedural-document-drafter`).

## Правовая база

### Основной закон

**ФЗ от 13.03.2006 № 38-ФЗ «О рекламе»** — ключевые статьи для отраслевого фокуса проекта (фарма / БАД / медуслуги):

| Норма | Что регулирует |
|---|---|
| **ст. 5** | Общие требования к рекламе. Запрет недостоверной, недобросовестной, неэтичной, заведомо ложной, скрытой рекламы. Запрет на введение в заблуждение. Запрет утверждений о превосходстве без объективного основания (ч. 3 п. 1) |
| **ст. 7** | Товары, реклама которых не допускается (наркотические средства, психотропные вещества и пр.) |
| **ст. 21** | Реклама алкогольной продукции (ограничения по местам, времени, форме) |
| **ст. 24** | Реклама лекарственных средств, медицинских изделий, медицинских услуг, методов лечения, медицинской деятельности |
| **ст. 25** | Реклама биологически активных добавок (БАД), пищевых добавок, продуктов детского питания |

### Ответственность

- **ст. 14.3 КоАП РФ** — нарушение законодательства о рекламе. Штрафы для юрлиц по ч. 1 — от 100 000 до 500 000 ₽; за рекламу ЛС / БАД с нарушениями ст. 24-25 — повышенные размеры по ч. 5 (от 200 000 до 500 000 ₽).
- **ст. 14.3.1 КоАП РФ** — нарушение требований к рекламе финансовых услуг.
- Срок давности по ст. 4.5 КоАП РФ — **1 год** для нарушений законодательства о рекламе.

### Процедурная база

- **ФЗ-248** «О государственном контроле (надзоре)…» — ФАС применяет процедуру КНМ при проверках. См. `references/fz248-knm-rospotrebnadzor.md` (применимо аналогично к ФАС с учётом разграничения компетенции);
- **Постановление Пленума ВС РФ от 24.10.2006 № 18** (применительно к КоАП по рекламе — `[ПРОВЕРИТЬ АКТУАЛЬНОСТЬ]`);
- **Гл. 24 АПК РФ** — оспаривание решений ФАС в арбитражном суде;
- **Гл. 22 АПК РФ** — рассмотрение дел об АП.

### Подзаконные и разъяснения

- **Письма ФАС** по отдельным категориям рекламы — официальные позиции, которые могут быть основанием для штрафа;
- **Разъяснения ФАС** на сайте fas.gov.ru;
- Региональные решения УФАС — публикуются на территориальных порталах, агрегированы в базе fas-search.

## Типовые рисковые формулировки (red flags)

Skill при проверке креатива обязан вытащить из текста все потенциально рискованные элементы и проверить их в базе ФАС.

### Категория 1 — Утверждения превосходства (ч. 3 п. 1 ст. 5)

| Маркер | Что нарушает | Что искать в базе |
|---|---|---|
| «Лучший», «№1», «первый», «единственный», «эталон», «лидер рынка» | Утверждение превосходства без объективного критерия и подтверждения | «утверждение превосходства», «лучший», «№1» |
| «Уникальный» | Может быть как описание свойства (ОК), так и заявление о превосходстве (риск) | «уникальный реклама» |
| «Премиум», «элит» | Обычно описание ценовой категории, но в спорных случаях — превосходство | «премиум реклама» |

### Категория 2 — Недостоверность свойств (ч. 3 пп. 2-4 ст. 5)

| Маркер | Что нарушает |
|---|---|
| «Гарантированно», «100% результат», «обязательно поможет», «вылечит» | Недостоверные сведения об эффекте товара |
| «Без побочных эффектов», «безопасно для всех» | Недостоверные сведения о безопасности; для ЛС / БАД — нарушение ст. 24 / 25 |
| «Не имеет аналогов», «не имеет противопоказаний» | Недостоверность + для ЛС / БАД — прямое нарушение ст. 24 / 25 |
| Конкретные числовые показатели эффективности без указания источника | Недостоверность; нужен ОСИ на исследование |

### Категория 3 — Реклама ЛС, БАД, медуслуг (ст. 24-25)

| Маркер | Норма-основание |
|---|---|
| Реклама рецептурных ЛС вне специализированных мероприятий / изданий | ст. 24 ч. 8 |
| Отсутствие предупреждения о консультации со специалистом для ЛС / медуслуг | ст. 24 ч. 7 |
| Обращение к несовершеннолетним в рекламе ЛС / БАД | ст. 24 ч. 1 п. 1 / ст. 25 ч. 1 п. 4 |
| Создание впечатления, что обращение к врачу не требуется | ст. 24 ч. 1 п. 1 |
| Гарантия положительного действия / безопасности БАД | ст. 25 ч. 1 п. 1 |
| Использование медицинских терминов в рекламе БАД (создаёт впечатление, что БАД — лекарство) | ст. 25 ч. 1 п. 2 |
| Утверждение лечебных свойств БАД | ст. 25 ч. 1 п. 2 |
| Ссылки на конкретные случаи излечения от заболеваний | ст. 25 ч. 1 п. 3 |
| Ссылки на одобрение / поддержку медиков / врачей | ст. 25 ч. 1 п. 3 |
| Образ медицинских / фармацевтических работников | ст. 25 ч. 1 п. 4 |
| Отсутствие пометки «Биологически активная добавка. Не является лекарственным средством» | ст. 25 ч. 2 |

### Категория 4 — Сравнение (ч. 3 п. 1 ст. 5, ст. 5 ч. 2)

| Маркер | Что нарушает |
|---|---|
| Сравнение с конкретным конкурентом (по названию / явно узнаваемо) | Некорректное сравнение, недобросовестная реклама |
| «Лучше, чем X» / «эффективнее аналогов» без указания критерия | Утверждение превосходства + некорректное сравнение |
| «Дешевле всех», «выгоднее всех» — без подтверждения | Недостоверность сведений о цене |

### Категория 5 — Скрытая реклама и недоговорные формы (ст. 5 ч. 9)

| Маркер | Что нарушает |
|---|---|
| Нативная реклама без пометки «реклама» / «на правах рекламы» | Скрытая реклама — ст. 5 ч. 9 |
| Отсутствие токена ОРД (для интернет-рекламы) | Нарушение требований к интернет-рекламе |
| Реклама в виде новости / редакционного материала | Скрытая реклама |

## Алгоритм проверки креатива (используется skill-ом)

См. `skills/fas-ad-practice-search/SKILL.md` — 7-шаговый пайплайн:
1. Квалификация вопроса (продукт / канал / спорная фраза / норма);
2. Поисковые гипотезы (точная фраза, юр. категория, синонимы, отрасль, год);
3. Поиск через `search_fas_ad_practice` (2-4 запроса);
4. Отбор дел (3-7 наиболее близких);
5. Анализ (что ФАС считала нарушением, факты, риск);
6. Вывод (риск низкий/средний/высокий, что менять);
7. Черновик (memo / ответ ФАС / правки текста).

## Шаблоны итоговых документов

### Шаблон memo бизнесу

```markdown
# Memo: рекламный креатив «[название/идентификатор]»

## 1. Резюме
- **Риск претензий ФАС**: высокий / средний / низкий
- **Применимые нормы**: ст. X, Y ФЗ «О рекламе»; ст. 14.3 КоАП
- **Рекомендация**: запускать / запускать с правками / переделать / снять

## 2. Анализируемый материал
[Текст / описание креатива / канал распространения]

## 3. Найденные рисковые формулировки

| Формулировка | Норма | Риск | Что менять |
|---|---|---|---|
| «лучший» | ст. 5 ч. 3 п. 1 | высокий | заменить на конкретное свойство |
| ... | ... | ... | ... |

## 4. Релевантная практика ФАС
[2-5 дел с docId из базы fas-search, краткое описание, год]

## 5. Рекомендованные правки (компонент 1 — как исправить)
- [конкретное место в тексте] — [как изменить] — [почему]

## 6. Стоимость риска для бизнеса и принятие риска (компонент 2)
По каждому существенному нарушению — цена вопроса, а не только уровень риска:
- **Штраф**: размер и норма (ст. 14.3 КоАП РФ — ч. 1 для юрлиц 100 000–500 000 ₽; ЛП/БАД по ст. 24–25 — ч. 5, 200 000–500 000 ₽; сумму/редакцию проверять через `route_norm_verification(jurisdiction="RU", probe=true)` и `usable_now: true`);
- **Иные последствия**: непрохождение согласования канала/площадки (ТВ — НРА), снятие/переделка и пересъёмка ролика (стоимость и сроки), срыв сроков кампании, предписание ФАС, репутация, повторность;
- **Совокупная «цена вопроса»** одной строкой для бизнеса;
- **Принятие риска**: запуск без устранения = решение бизнеса о принятии риска (`[ВОПРОС БИЗНЕСУ]`); блокирующий риск принять нельзя — указать прямо.

## 7. Заметка юристу
- [СТРАТЕГИЧЕСКОЕ РЕШЕНИЕ ЮРИСТА]: ...
- [ПРОВЕРИТЬ ИСТОЧНИК]: ...
```

### Шаблон обоснования позиции в ответе ФАС

Используется вместе с `skills/gov-response/SKILL.md`. См. там структуру.

Содержательная часть от `fas-ad-practice-search`:
- IRAC по каждому пункту запроса;
- Привязка к практике ФАС с противоположным выводом (если есть);
- Привязка к разъяснениям ФАС / Пленума ВС;
- Контр-аргументы по ключевым формулировкам.

### Шаблон процессуального документа

Используется вместе с `skills/procedural-document-drafter/SKILL.md`. Используется в:
- **Объяснение по ст. 25.1 КоАП РФ** по делу о нарушении ст. 14.3;
- **Возражение на протокол об АП**;
- **Ходатайство** (об отложении / истребовании / экспертизе);
- **Жалоба на постановление по делу об АП** (ст. 30.1-30.3 КоАП);
- **Заявление в АС об оспаривании решения ФАС** (гл. 24 АПК).

Содержательная часть от `fas-ad-practice-search`:
- Подбор практики ФАС / судов в свою пользу;
- Демонстрация различия фактических обстоятельств с делами, где ФАС нашла нарушение;
- Критика правовой квалификации с опорой на практику.

## Уровни риска (адаптация общей шкалы для рекламы)

См. общую `references/risk-scale.md`. Поправки для рекламных кейсов:

| Уровень | Условие |
|---|---|
| **Блокирующий** | Прямое нарушение запрета ст. 24 / 25 (например, реклама рецептурного ЛС в массовых СМИ); тождество с фразой, по которой уже было >5 решений ФАС за последние 2 года с штрафами; нарушение ч. 3 ст. 5 при наличии возражений конкурентов в той же отрасли |
| **Высокий** | Использование явных маркеров категорий 1-3 без обоснования; ≥3 решений ФАС за последний год по аналогичным формулировкам |
| **Средний** | Спорная формулировка, для которой практика ФАС неоднозначна; возможно отбиться при правильной аргументации, но риск возражений сохраняется |
| **Низкий** | Маркеров нет либо они нейтрализованы (есть обоснование, ссылка на исследование, корректное сравнение); практика ФАС не находит аналогичных нарушений |
| **Вопрос бизнесу** | Технически — нарушение незначительное, но коммерческий эффект формулировки большой → решение о принятии риска штрафа за бизнесом |

## Что запрещено

- **Не давать категоричное «можно»** по креативу без проверки в базе ФАС — даже при отсутствии явных маркеров есть отраслевая специфика.
- **Не выдумывать** docId, даты, нарушителей. Если Overlay не вернул результат — так и пишется.
- **Не маркировать риск «низкий»** без минимум 3 поисковых запросов по разным гипотезам — это требование пайплайна.
- **Не подменять решение бизнеса** в категории «вопрос бизнесу».
- **Не использовать практику регионального УФАС как обязательную** для других регионов — фиксировать как «практика [регион]».

## Маркеры

Общий реестр маркеров — `references/citation-rules.md`, «Реестр маркеров неполноты». Ниже — маркеры слоя «реклама/практика ФАС»:

- `[ПРОВЕРИТЬ ИСТОЧНИК]` — нужно раскрыть карточку через `get_fas_case` и сверить с официальной публикацией на fas.gov.ru;
- `[ПРОВЕРИТЬ АКТУАЛЬНОСТЬ ПРАКТИКИ]` — дело старше 2 лет, проверить, не изменился ли подход;
- `[ПРОВЕРИТЬ ОТРАСЛЕВУЮ СПЕЦИФИКУ]` — практика по другой отрасли, нужно проверить релевантность;
- `[СТРАТЕГИЧЕСКОЕ РЕШЕНИЕ ЮРИСТА]` — выбор: переделать креатив / принять риск / запросить разъяснение ФАС;
- `[ВОПРОС БИЗНЕСУ]` — коммерческий trade-off (риск штрафа vs эффективность формулировки).

## Ограничения текущей методики (MVP)

1. **База fas-search покрывает решения о нарушениях ФЗ "О рекламе"** — не покрывает другие категории дел ФАС (картели, недобросовестная конкуренция вне рекламы, закупки).
2. **Лимит 300 запросов/сутки** на IP — для типовой проверки одного креатива (2-4 запроса) более чем достаточно, но при массовом аудите портфеля учитывать.
3. **Поиск по тексту**, не по изображению — креативы с минимальным текстом или без него не полностью покрываются (визуальная часть проверяется юристом отдельно).
4. **Региональные особенности** — практика разных УФАС может различаться, skill отмечает регион в карточке.
5. **Не покрывается актуальность подзаконных актов** — при критичной позиции применить capability-маршрут нормы; ведомственную практику открыть на fas.gov.ru.
