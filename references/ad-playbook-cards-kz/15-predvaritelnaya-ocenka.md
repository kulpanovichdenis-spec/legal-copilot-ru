# 15. Предварительная оценка / заключение о соответствии рекламы

Карточка рекламного плейбука РК. Вход и алгоритм — `references/ad-creative-playbook-kz.md`. Нормы — веб-выверка на adilet.

**Нормы** `[ПРОВЕРИТЬ ИСТОЧНИК — не в локальной базе]`: Кодекс РК «О здоровье народа» № 360-VI, ст. 56 (`https://adilet.zan.kz/rus/docs/K2000000360`); порядок оценки рекламных материалов — Национальный научный центр развития здравоохранения (НЦРЗ, `https://nrchd.kz/ads-evaluation`).

**Суть** (по ТЗ 5.2): для рекламы в области здравоохранения предусмотрен порядок получения **заключения о соответствии** рекламы законодательству. Отдельно описать: процедуру оценки материала; комплект документов; сроки; порядок изменения утверждённого материала; случаи повторной оценки.

**Триггеры**: реклама ЛП для населения; случаи, когда закон/регулятор требует предварительной оценки; существенное изменение уже одобренного материала.

**Workflow** `[КОРПОРАТИВНЫЙ СТАНДАРТ]`: финальный материал → medical/regulatory/legal review → язык (карточка 2) → подача на заключение (НЦРЗ) → получение заключения → version lock → публикация → проверка фактического размещения → архив. Существенное изменение после заключения → повторная оценка.

**Учебные сценарии**:
- `[УЧЕБНЫЙ СЦЕНАРИЙ]` OTC-ролик вышел без заключения о соответствии, где оно требуется → процедурное нарушение (сверить обязательность по ст. 56/ДСМ-288).
- `[УЧЕБНЫЙ СЦЕНАРИЙ]` После заключения изменили ключевой claim → нужна повторная оценка.

**Реальная практика**: в локальной базе не проверялось; порядок — НЦРЗ nrchd.kz.

**Когда допустимо / как исправить**:
- Было: публикация без требуемого заключения. Стало: пройти оценку/получить заключение до публикации, зафиксировать version lock. Почему: ст. 56 Кодекса о здоровье (порядок заключения о соответствии).

**Где искать**: adilet — Кодекс о здоровье ст. 56; НЦРЗ `https://nrchd.kz/ads-evaluation`.
