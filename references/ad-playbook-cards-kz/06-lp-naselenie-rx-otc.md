# 6. Лекарственные препараты для населения: Rx / OTC

Карточка рекламного плейбука РК. Вход и алгоритм — `references/ad-creative-playbook-kz.md`. Нормы — веб-выверка на adilet.

**Нормы** `[ПРОВЕРИТЬ ИСТОЧНИК — не в локальной базе]`: Кодекс РК «О здоровье народа» № 360-VI, ст. 56 (`https://adilet.zan.kz/rus/docs/K2000000360`); приказ МЗ РК № ҚР ДСМ-288/2020 «Правила рекламы лекарственных средств и медицинских изделий» (`https://adilet.zan.kz/rus/docs/V2000021872`).

**Ключевые правила** (по ТЗ 5.2, сверить по ДСМ-288/ст.56):
- запрет рекламы **незарегистрированных** препаратов (карточка 5);
- разграничение Rx и OTC;
- **запрет рекламы Rx в СМИ для населения**;
- соответствие рекламы утверждённой инструкции по применению;
- обязательные сведения по каждому формату + предупреждения;
- требования к казахской и русской версиям (карточка 2);
- порядок получения **заключения о соответствии** рекламы законодательству в области здравоохранения (карточка 15).

**Триггеры**: рецептурный препарат в массовом канале; claims вне инструкции; OTC-реклама без предупреждения.

**Учебные сценарии**:
- `[УЧЕБНЫЙ СЦЕНАРИЙ]` Рекламный ролик рецептурного препарата на ТВ для населения → запрет Rx в СМИ для населения (карточка 5 gate + ст. 56).
- `[УЧЕБНЫЙ СЦЕНАРИЙ]` OTC-реклама с показанием, которого нет в инструкции → несоответствие утверждённой инструкции.

**Реальная практика**: в локальной базе не проверялось; разъяснения — комитет медфармконтроля gov.kz.

**Когда допустимо / как исправить**:
- Было: Rx-препарат в рекламе для населения. Стало: перевести в HCP-канал (карточка 8) либо unbranded disease-awareness без препарата (карточка 12). Почему: запрет Rx для населения.
- Было: OTC-claim вне инструкции. Стало: показания строго по инструкции + обязательное предупреждение (карточка 7). Почему: соответствие инструкции (ДСМ-288).

**Где искать**: adilet — Кодекс о здоровье ст. 56, ДСМ-288; заключение — карточка 15.
