# 2. Язык рекламы (казахский / русский)

Карточка рекламного плейбука РК. Вход и алгоритм — `references/ad-creative-playbook-kz.md`. Нормы — веб-выверка на adilet.

**Нормы** `[ПРОВЕРИТЬ ИСТОЧНИК — не в локальной базе]`: Закон РК «О языках» (`https://adilet.zan.kz/rus/docs/Z970000151_`); специальные языковые требования приказа МЗ РК № ҚР ДСМ-288/2020 (реклама ЛС, `https://adilet.zan.kz/rus/docs/V2000021872`) и № ҚР ДСМ-160/2020 (реклама БАД, `https://adilet.zan.kz/rus/docs/V2000021544`).

**Триггеры**: реклама только на одном языке; перевод обязательного предупреждения; ТВ/радио/печать/интернет — разные требования.

**Языковая матрица** (по ТЗ; конкретику сверить по действующим редакциям):
- ЛП: специальное языковое требование по ДСМ-288 — проверить для казахского и русского;
- БАД (ТВ, радио, печать): по действующей редакции ДСМ-160;
- БАД (интернет): отдельный анализ (открытый вопрос ТЗ после изменений 2024 г. — приказ № 36/2024);
- онлайн-реклама: по правилам маркировки (Закон 18-VIII).

**Корпоративный стандарт** `[КОРПОРАТИВНЫЙ СТАНДАРТ]`: все материалы для населения по ЛП/БАД готовятся **на казахском и русском**, если Legal письменно не согласовал исключение. Это внутренний стандарт, который может быть строже закона.

**Учебные сценарии**:
- `[УЧЕБНЫЙ СЦЕНАРИЙ]` ТВ-ролик OTC только на русском, предупреждение только на русском → проверить требование ДСМ-288/Закона о языках; по корпоративному стандарту нужны обе версии.

**Реальная практика**: в локальной базе не проверялось.

**Когда допустимо / как исправить**:
- Было: креатив на одном языке. Стало: казахская и русская версии; предупреждение — из официального акта на обоих языках. Почему: Закон о языках + спец. требования ДСМ.

**Где искать**: adilet — Закон о языках, ДСМ-288, ДСМ-160.
