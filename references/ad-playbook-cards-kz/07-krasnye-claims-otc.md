# 7. Красные claims OTC (лекарственные препараты)

Карточка рекламного плейбука РК. Вход и алгоритм — `references/ad-creative-playbook-kz.md`. Нормы — веб-выверка на adilet.

**Нормы** `[ПРОВЕРИТЬ ИСТОЧНИК — не в локальной базе]`: приказ МЗ РК № ҚР ДСМ-288/2020 (`https://adilet.zan.kz/rus/docs/V2000021872`); Кодекс о здоровье ст. 56.

**Красные claims OTC** (по ТЗ 5.2 — выносить на обязательный Legal/сверку с ДСМ-288):
- гарантия результата;
- заявления о безопасности / «без побочных эффектов»;
- сравнение препаратов (некорректное);
- рекомендации врачей и государственных органов;
- использование детей;
- описание лечения отдельных заболеваний в рекламе для населения.

**Триггеры**: «гарантированный результат», «абсолютно безопасно / без побочных», «одобрено врачами / Минздравом», сравнение с конкурентом, детские образы, «вылечит болезнь X».

**Учебные сценарии**:
- `[УЧЕБНЫЙ СЦЕНАРИЙ]` «Гарантируем: вылечит кашель без побочных эффектов» → гарантия результата + заявление о безопасности + лечение заболевания, ДСМ-288.
- `[УЧЕБНЫЙ СЦЕНАРИЙ]` «Рекомендовано Министерством здравоохранения» → рекомендация госоргана (запрет).

**Реальная практика**: в локальной базе не проверялось.

**Когда допустимо / как исправить**:
- Было: «Гарантированно и безопасно, одобрено врачами». Стало: показания строго по инструкции без гарантии/безопасности/рекомендаций врачей + обязательное предупреждение (противопоказания, инструкция) на обоих языках. Почему: ДСМ-288.
- Было: детский образ в OTC-рекламе. Стало: убрать использование детей (сверить допустимость по ДСМ-288/ст.56). Почему: ограничение на использование детей.

**Где искать**: adilet — ДСМ-288, Кодекс о здоровье ст. 56.
