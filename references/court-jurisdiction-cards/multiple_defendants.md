# Карточка: Несколько ответчиков

## Триггер
Иск заявлен одновременно к нескольким ответчикам, находящимся/проживающим в разных местах.

## Ключевые нормы
- **Ст. 31 ч. 1 ГПК РФ** — иск к нескольким ответчикам, проживающим или находящимся в разных местах, предъявляется в суд по месту жительства или месту нахождения **одного из ответчиков по выбору истца**.
- **АПК РФ** — аналогичное правило выбора истца при нескольких ответчиках, находящихся на территориях разных субъектов РФ (в рамках общих правил ст. 36 АПК о подсудности по выбору истца).
- **КАС РФ ст. 24** — аналогичное правило для административного истца при нескольких административных ответчиках.

## Что меняет
Территориальная подсудность становится **альтернативной по выбору истца** (не единственно верный суд) — попадает в P5/P8 priority engine. Skill возвращает все варианты (по каждому ответчику), не выбирает один.

## Частые ошибки
- Определять суд только по адресу «основного» или «первого» ответчика, не указывая, что выбор — за истцом среди адресов всех ответчиков.
- Не проверять, что все ответчики являются надлежащими соответчиками по одному материальному правоотношению (объединение ответчиков не по формальному признаку, а по существу требования) — иначе объединение может быть процессуально необоснованным (это уже вопрос за пределами scope skill, но заслуживает WARNING юристу).

## Мини-процедура
1. Собрать адреса/места нахождения всех ответчиков (jurisdiction anchor по каждому).
2. Сформировать список вариантов территориальной подсудности — по одному на каждого ответчика.
3. Проверить, не действует ли для кого-то из ответчиков исключительная подсудность (P4) — если да, она приоритетнее общего правила выбора по нескольким ответчикам.
