# Карточка: Интеллектуальная собственность — свой sub-router

## Триггер
Товарный знак, патент, авторское право, ноу-хау, доменное имя, акт Роспатента — упоминаются в фактах дела.

## Запрещённая логика (ТЗ §25)
```
есть товарный знак / патент / авторское право → Суд по интеллектуальным правам
```
Это неверно. **Только категории, прямо отнесённые законом к СИП как первой инстанции**, направляются туда напрямую. Остальные IP-споры идут по обычным правилам (арбитраж/СОЮ по субъектам и характеру).

## Sub-router — минимум различаемых категорий

| Категория | Первая инстанция | Основание |
|---|---|---|
| Оспаривание предоставления или прекращения правовой охраны товарного знака/патента (недействительность регистрации) | **СИП** | Прямое указание закона — специальная подведомственность СИП как суду первой инстанции |
| Оспаривание ненормативного правового акта / решения Роспатента (отказ в регистрации, признание недействительным патента административным порядком) | **СИП** | Прямое указание закона |
| Оспаривание нормативных актов в сфере интеллектуальных прав | **СИП** | Прямое указание закона |
| Нарушение исключительного права (использование без разрешения) | Обычный арбитражный суд субъекта (если стороны/деятельность — экономическая) либо СОЮ (если нет экономического характера, например физлицо-нарушитель вне предпринимательской деятельности) | Общие правила АПК/ГПК, ст. 27 АПК / ст. 22 ГПК |
| Компенсация за нарушение исключительного права | Туда же, где рассматривается нарушение | — |
| Лицензионный спор (взыскание лицензионных платежей, расторжение лицензии) | Обычный суд по договорной природе спора | Общие правила |
| Договор об отчуждении исключительного права | Обычный суд по договорной природе спора | Общие правила |
| Доменный спор (не являющийся спором о самом знаке) | Обычный суд, защита по ст. 1252, 1484 ГК РФ | Общие правила |
| Иные IP-категории (служебное произведение, соавторство, право на вознаграждение изобретателя) | Обычно СОЮ (личные неимущественные/трудовые аспекты) либо арбитраж (если между хозяйствующими субъектами) | Определяется по субъектам/характеру, не по факту наличия IP |

`[ПРОВЕРИТЬ АКТУАЛЬНОСТЬ РЕДАКЦИИ]` — точный перечень категорий прямой подведомственности СИП как первой инстанции закреплён отдельным федеральным законом/ФКЗ о судах и может уточняться практикой; при пограничном случае — сверить действующий перечень напрямую, не полагаться на память.

## Территориальная подсудность
Для дел СИП как первой инстанции — специальная (сам СИП, не «арбитражный суд субъекта»). Для остальных IP-категорий — общие правила АПК/ГПК (P9), без специфики.

## Частые ошибки
- Направлять любой спор о нарушении права на товарный знак в СИП (это компетенция обычного арбитражного суда/СОЮ, а не СИП).
- Не проверять экономический характер деятельности при квалификации нарушения исключительного права физлицом — определяет АПК или ГПК.
