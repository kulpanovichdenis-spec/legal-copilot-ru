# Карточка: Филиалы и представительства

## Триггер
Ответчик — организация, спор вытекает из деятельности её филиала или представительства, находящегося не по адресу головной организации.

## Ключевые нормы
- **Ст. 29 ч. 2 ГПК РФ** — иск к организации, вытекающий из деятельности её филиала или представительства, может быть предъявлен также в суд по месту нахождения её филиала или представительства.
- **АПК РФ** — аналогичное правило подсудности по выбору истца по месту нахождения филиала/представительства для споров, вытекающих из его деятельности (в рамках ст. 36 АПК о подсудности по выбору истца).

## Что меняет
Территориальная подсудность становится **альтернативной** (P5) — истец вправе выбрать между адресом головной организации (общее правило, P9) и адресом филиала/представительства, если спор именно из его деятельности.

## Частые ошибки
- Применять правило о филиале к любому спору с организацией, у которой есть филиалы, а не только к спору, **вытекающему из деятельности конкретного филиала**.
- Использовать устаревший адрес филиала без проверки его актуальной регистрации (филиалы указываются в ЕГРЮЛ организации).

## Мини-процедура
1. Подтвердить, что предмет спора связан именно с деятельностью филиала (например, договор заключён и исполнялся филиалом), а не просто с тем, что филиал существует.
2. Сверить адрес филиала по ЕГРЮЛ (актуальность — через `counterparty-check`/DaData), не по устаревшим данным из договора.
3. Сформировать оба варианта (адрес головной организации / адрес филиала) как альтернативные.
