# Карточка: Трудовые споры

## Триггер
Спор между работником и работодателем, вытекающий из трудовых отношений (взыскание зарплаты, восстановление на работе, оспаривание дисциплинарного взыскания, материальная ответственность).

## Ключевые нормы
- **Ст. 28-29 ГПК РФ** — общая подсудность по адресу ответчика-работодателя + альтернативная подсудность по месту жительства истца-работника либо по месту исполнения трудового договора (специальное правило ГПК для трудовых споров).
- **НК РФ ст. 333.36 п. 1 пп. 1** (сверено дословно 2026-09-16, pravo.gov.ru) — истцы по искам о взыскании заработной платы (денежного содержания) и иным требованиям, вытекающим из трудовых правоотношений, а также по искам о взыскании пособий, освобождаются от уплаты государственной пошлины полностью, независимо от суммы иска. **Только ГПК/СОЮ** — в ст. 333.37 НК РФ (арбитраж) аналогичной трудовой льготы нет вообще; трудовые споры между организациями (например, о взыскании компенсации по трудовому спору руководителя-единоличного исполнительного органа, если он рассматривается в арбитраже) льготы не получают.

## Что меняет
- **Территориальная подсудность**: альтернативная — работник вправе выбрать суд по своему месту жительства или по месту исполнения трудового договора, не только по адресу работодателя.
- **Госпошлина**: полное освобождение работника-истца (не работодателя — если иск подаёт работодатель, например о возмещении ущерба, льгота не действует).

## Частые ошибки
- Освобождать от пошлины работодателя, выступающего истцом (льгота — только для работника как истца по требованиям, вытекающим из трудовых отношений).
- Не различать «спор из трудовых отношений» и гражданско-правовой спор с формально бывшим работником (например, взыскание неосновательного обогащения после увольнения по основаниям, не связанным с трудовым договором) — требует проверки правовой природы требования, а не только субъектного состава.
- Применять общую подсудность по адресу работодателя без учёта права работника на альтернативный выбор.

## Мини-процедура
1. Подтвердить, что требование действительно вытекает из трудовых отношений (не гражданско-правовой договор подряда/оказания услуг, формально названный «трудовым»).
2. Определить субъекта, выступающего истцом — от этого зависит применение льготы по пошлине.
3. Сформировать альтернативные варианты территориальной подсудности (адрес работодателя / место жительства работника / место исполнения трудового договора).
4. Вызвать калькулятор с `--exemption labor_claims`, если истец — работник.
