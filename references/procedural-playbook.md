# Procedural Playbook

Назначение: единый перечень правил и проверок для процессуальных и претензионных документов. Используется `procedural-document-drafter`, `position-critic` и соответствующим agent. Общий метод отдельного аргумента и его связи с утверждённым анализом — `references/procedural-argument-method.md`.

Все материалы — черновики. Финальное решение и подача — за юристом.

Открывать только файл нужного раздела из `references/procedural-playbook/`. Этот файл — оглавление.
