# Рекламный плейбук РК — индекс направлений анализа рекламного креатива (ЛП/БАД)

Плейбук проекта для проверки рекламных материалов по **лекарственным препаратам и БАД на соответствие законодательству Республики Казахстан**. Это **индекс-роутер**: краткие определения направлений + таблица триггеров. Содержательный материал — в карточках `references/ad-playbook-cards-kz/` (локальные `.md`, единственный содержательный источник плейбука).

**Юрисдикция — РК.** Не смешивать с РФ и РУз. Российский (`references/ad-creative-playbook.md`) и узбекский (`references/ad-creative-playbook-uz.md`) плейбуки к казахстанскому креативу **не применять**.

> ⚠️ **KZ-нормы всегда требуют выверки актуальной редакции.** Сначала вызвать `route_norm_verification(jurisdiction="KZ", probe=true)` и использовать подключённый provider только при `usable_now: true`. Если такого маршрута нет, открыть полный текст вручную на **adilet.zan.kz** и до подтверждения сохранять `[ПРОВЕРИТЬ ИСТОЧНИК — не в локальной базе]`. Карточка и URL — только навигация; общее знание модели проверку не заменяет.

**Правило подгрузки: не читать все карточки.** Классифицировать креатив по таблице триггеров и открыть только сработавшие (обычно 2–5).

**Доступ к карточкам — локальные `.md` в `references/ad-playbook-cards-kz/`** (единственный источник, 16 карточек). Открывать файл по таблице триггеров. Ранее карточки жили на серверном слое `legal-kb` (инструменты `search_ad_playbook`/`get_ad_playbook_card`); 2026-09-11 они релокализованы в репозиторий в связи с выводом сервера. UZ и KZ не смешивать; российский `references/ad-creative-playbook.md` и узбекский `references/ad-creative-playbook-uz.md` плейбуки к казахстанскому креативу не применять. Карточка — методический слой, **не НПА**: цитировать как закон нельзя, учебный сценарий не выдавать за практику.

**Статус.** Методологическая база проекта. Результат — всегда черновик для юриста; финал и подача — за юристом.

**Происхождение и права.** Структура следует Кодексу РК «О здоровье народа» (ст. 56), Закону «О рекламе» № 508-II и правилам приказов ДСМ (по ТЗ `workflow/TZ_reklamnyi_playbook_Kazakhstan_LP_BAD.md`). Тексты норм — официальные акты adilet.zan.kz; плейбук написан для проекта заново.

## Языки рекламных материалов

Реклама для населения по ЛП/БАД готовится на **казахском и русском** (Закон о языках; специальные требования приказов ДСМ-288/160). Плейбук — на русском. Обязательные формулировки предупреждений — из официального акта, не выдумывать.

## Алгоритм работы агента

1. **Вход**: креатив + объект (ЛП Rx/OTC / БАД) + канал + аудитория (население / HCP).
2. **Gate-проверки**: (а) регистрация продукта и допуск к обращению в РК, реестр ЕАЭС для БАД (карточка 5); (б) Rx/OTC; (в) язык (карточка 2).
3. **Классификация** по таблице триггеров.
4. **Подгрузка** сработавших карточек из `references/ad-playbook-cards-kz/` (файл — по строке таблицы триггеров ниже). Отделить норму / рабочую интерпретацию / корпоративный стандарт / учебный сценарий / реальную практику.
5. **Выверка нормы (обязательна для KZ)**: route → `usable_now: true`; при отсутствии подключённого маршрута — вручную открыть полный текст на adilet.zan.kz. Проверить редакцию, статус и pinpoint. До этого маркер остаётся; наличие URL ≠ актуальность.
6. **Вывод (два компонента)**: риск по `references/risk-scale.md`; **компонент 1** — правки «Было → Стало → Почему»; **компонент 2** — стоимость риска для бизнеса и принятие риска (санкция по КоАП РК за нарушение рекламы/ст. 56 Кодекса о здоровье — сверять по adilet.zan.kz, `[ПРОВЕРИТЬ ИСТОЧНИК]`; иные последствия — непрохождение согласования канала, переделка ролика, срыв сроков; доведение суммы риска до бизнеса, запуск без устранения = принятие риска бизнесом, блокирующий риск принять нельзя). Правило — CLAUDE.md, «Блок „что поправить“». Результат — в `workflow/`.

## Ограничения (учитывать в каждом выводе)

- **Полнотекстового поиска по KZ-корпусу пока нет** — корпус `kazakh-legal-memory` на сервере зарегистрирован, но MCP-инструментов поиска по нему не опубликовано; каждая норма требует веб-выверки, статьи/пункты/редакции сверять по adilet на дату задачи. Акты ЕАЭС — не национальные акты РК, не смешивать.
- **Практики почти нет** — «учебные сценарии» в карточках помечены `[УЧЕБНЫЙ СЦЕНАРИЙ]` (иллюстрация нормы, не практика); реальная практика — по официальным разъяснениям регуляторов (nrchd.kz, комитеты gov.kz), открывать первоисточник.
- **ЕАЭС-слой**: БАД и пищевая продукция регулируются в т. ч. техрегламентами ЕАЭС (ТР ТС 021/022/027) и Единым реестром свидетельств о госрегистрации ЕАЭС.

## Типовые связки карточек
