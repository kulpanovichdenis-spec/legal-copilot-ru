# Контроль человека

Уровень ставится на задачу, не на весь проект.

| Уровень | Смысл |
|---|---|
| L0 Human only | делает человек |
| L1 AI assistance | подсказка, текст наружу пишет человек |
| L2 AI draft + mandatory human review | черновик, без проверки нет эффекта |
| L3 AI action + human approval before effect | действие подготовлено, эффект после одобрения |
| L4 AI action + exception review | идёт само, человек смотрит исключения |
| L5 autonomous | без человека на каждом шаге; только после отдельного решения |

От чего зависит уровень: риск, обратимость, внешний эффект, опора на источник, конфиденциальность, privilege, возможность аудита, заметность ошибки.

L4 и L5 не ставить, пока пользователь отдельно не подтвердил решение через `python tools/legal_ops/ops.py decide`.

Security и privacy по конкретному продукту не объявлять «закрытыми» из этого файла. Вопросы для IT и InfoSec — в треке `references/legal-ops/ai-evaluation.md`.
