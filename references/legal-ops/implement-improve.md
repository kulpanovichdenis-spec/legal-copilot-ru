# IMPLEMENT и проверка эффекта

Читать, когда `current_phase` = `implement`. Эта карточка входит в структуру skill. Живой пилот не считается доказанным, пока проект не прошёл его на реальной работе.

## Чек-лист внедрения

Процесс обновлён; роли и права заданы; безопасность и приватность проверены профильными владельцами; интеграция, журнал и запасной путь есть; обучение, поддержка и владелец названы; есть порядок обновления и разбор инцидента.

## Изменение привычки

ADKAR (Awareness, Desire, Knowledge, Ability, Reinforcement) применять, только если без него неясно, почему решением не пользуются. Не навешивать рамку ради рамки.

## Обзор после запуска

Смотреть: пользуются ли, фактический объём, цикл, качество, ошибки, переделки, обходы, эскалации, эффект для бизнеса, новые узкие места. Ориентиры — 30, 90 и 180 дней; сдвигать, если процесс живёт в другом ритме. Сравнение цифр — `python tools/legal_ops/ops.py compare`.

## DONE WHEN

Есть владелец, процессом пользуются, baseline сравнён с фактом, отклонения объяснены, появились следующие улучшения, `project_state.yaml` обновлён через `python tools/legal_ops/ops.py`.
