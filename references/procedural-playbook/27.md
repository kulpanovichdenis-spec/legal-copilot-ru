## 27. Возражения на отзыв (письменные пояснения истца)

### 27.1 Назначение и процессуальная форма

Документ истца (заявителя) в ответ на отзыв ответчика. Специальной статьи для «возражений на отзыв» в АПК / ГПК нет — процессуальная форма:
- **АПК**: письменные объяснения лица, участвующего в деле (ст. 81 АПК РФ) — приобщаются к материалам дела;
- **ГПК**: объяснения суду в письменной форме, право приводить доводы и возражать относительно доводов других лиц (ч. 1 ст. 35 ГПК РФ).

Типовые заголовки: «Возражения на отзыв ответчика», «Письменные объяснения истца», «Возражения на отзыв ответчика в порядке ст. 81 АПК РФ». Название выбирается по задаче и терминологии материалов дела, а не по образцу. В ГПК процессуальная категория ч. 1 ст. 35 — **«объяснения»**; заголовок «пояснения» юрист исправил на «ОБЪЯСНЕНИЯ» (2026-09-02).

### 27.2 Главное содержательное правило

**Не пересказывать исковое заявление.** Позиция по существу уже изложена в иске; повтор ослабляет документ и раздражает суд. Отвечать только на **новые, спорные и существенные** доводы отзыва:

- новые основания и обстоятельства, впервые появившиеся в отзыве;
- искажения доказательств и выборочное цитирование;
- иную (неверную) хронологию событий;
- смешение документов, периодов, обязательств;
- попытку вывести правовое последствие из недоказанного факта;
- ошибочную правовую квалификацию.

Доводы отзыва, уже полностью закрытые текстом иска, — закрывать короткой отсылкой к соответствующему разделу иска, без развёрнутого повтора.

### 27.3 Структура

1. Шапка (суд → стороны (+ третьи лица) → номер дела) — по правилам раздела 15.1.
2. Заголовок (см. 27.1).
3. Короткое введение: каким отзывом вызван документ (дата, кем подан), общий тезис.
4. Блоки опровержения по существенным доводам отзыва — каждый отдельным подзаголовком (правило 15.3), внутри — формула 26.3.
5. Просительная часть — обычно поддержание заявленных требований; отдельная просьба формулируется, только если есть основание (например, о приобщении объяснений к материалам дела).
6. Приложения (новые документы — только если они отвечают на новые доводы отзыва; полномочия представителя — по 13.5; подтверждение направления другим лицам — по применимому кодексу).
7. Подпись + дата.

### 27.4 Что не делать

- Не повторять исковое заявление (см. 27.2).
- Не отвечать на каждый абзац отзыва подряд — только на существенные позиции (фильтр 26.2).
- Не заявлять в этом документе новых требований — для изменения основания или предмета иска есть ст. 49 АПК РФ / ст. 39 ГПК РФ и отдельное заявление.
- Не переходить на эмоциональные оценки отзыва — см. `house-style.md`.
- Не соглашаться с квалификацией оппонента однозначно: «договоры могут не образовывать…», а не «не образуют» — квалификацию даёт суд.
- Общие дефекты составления (приложения, реквизиты, «за суд», аналогия из другой системы судов) — 23.1.
