# Trademark Similarity Search — методика проверки товарных знаков

Методика проверки обозначения на **тождество** и **сходство до степени смешения** с ранее зарегистрированными товарными знаками. Используется skill-ом `trademark-search` (см. `skills/trademark-search/SKILL.md`) для **pre-filing screening** — быстрой проверки перед подачей заявки на регистрацию.

**Не заменяет** работу патентного поверенного и официальное заключение Роспатента: результат — методический отчёт для юриста, не основание для отказа от подачи заявки.

## Когда применяется

- Компания планирует регистрацию нового товарного знака (для нового продукта — БАД, ЛП, упаковка, сервис);
- При выборе из 2–5 рабочих названий — отсев заведомо рискованных вариантов;
- При получении уведомления Роспатента о схожих знаках — анализ конкретного противопоставления;
- Перед стартом маркетинговой кампании / выпуском продукта на рынок — снижение риска претензий правообладателей.

**Не применяется** для:
- полного FTO-исследования с заключением (для этого — патентный поверенный);
- защиты в споре по уже поданной заявке / зарегистрированному знаку (тогда — `procedural-document-drafter` + материальная база ниже);
- регистрации НМПТ, географических указаний, фирменных наименований, коммерческих обозначений (требуют отдельной методики).

## Правовая база

> **Existence-check обязателен, но это только discovery.** До сохранения отчёта правовые ссылки раскрываются через `route_norm_verification(jurisdiction="RU", probe=true)` только у provider с `usable_now: true`; проверить редакцию, статус, pinpoint и provenance. Не подтверждено — `[ПРОВЕРИТЬ НОРМУ]`, а не догадка. Редакции подзаконных актов и МКТУ — с `[ПРОВЕРИТЬ АКТУАЛЬНОСТЬ РЕДАКЦИИ]` при сомнении.

### Основания для отказа в регистрации

| Норма | Содержание |
|---|---|
| **п. 1 ст. 1483 ГК РФ** | Не регистрируются обозначения, не обладающие различительной способностью или состоящие только из элементов (вид товара, качество, время, место, способ производства и т. д.) |
| **п. 3 ст. 1483 ГК РФ** | Не регистрируются обозначения, противоречащие общественным интересам, морали |
| **п. 6 ст. 1483 ГК РФ** | Не регистрируются обозначения, **тождественные** или **сходные до степени смешения** с ранее зарегистрированными ТЗ в отношении **однородных товаров/услуг** (включая ТЗ с более ранним приоритетом, заявки, общеизвестные ТЗ, НМПТ) |
| **п. 7 ст. 1483 ГК РФ** | Не регистрируются обозначения, тождественные / сходные с НМПТ |
| **п. 8 ст. 1483 ГК РФ** | Не регистрируются обозначения, тождественные / сходные с фирменным наименованием или коммерческим обозначением, права на которое возникли ранее даты приоритета |
| **п. 9 ст. 1483 ГК РФ** | Не регистрируются обозначения, тождественные с известными произведениями науки/искусства, ФИО известных лиц без согласия |

### Подзаконные акты и руководства

- **Приказ Минэкономразвития РФ от 20.07.2015 № 482** (с изменениями) — Правила составления, подачи и рассмотрения документов, являющихся основанием для совершения юридически значимых действий по госрегистрации ТЗ;
- **Руководство по осуществлению административных процедур и действий в рамках предоставления государственной услуги по государственной регистрации товарного знака** (Роспатент) — детальная методология эксперта;
- **Постановление Пленума ВС РФ от 23.04.2019 № 10** «О применении части четвёртой ГК РФ» — раздел V (особенно пп. 154–165) — судебное толкование сходства и однородности.

### Международные акты

- **Парижская конвенция по охране промышленной собственности** 1883 г. — принцип национального режима, приоритет;
- **Мадридское соглашение** и **Мадридский протокол** — международная регистрация ТЗ через WIPO;
- **Соглашение ТРИПС** (ВТО) — минимальные стандарты охраны;
- **Договор о ЕАЭС** от 29.05.2014, раздел XXIII (ИС) — регулирование в рамках ЕАЭС.

## Критерии сходства до степени смешения

Оценка проводится по **4 критериям**, каждый отдельно + интегральная оценка общего впечатления (Пленум ВС № 10 п. 162).

### 1. Фонетическое сходство (звуковое)

| Признак | На что обратить внимание |
|---|---|
| Совпадение слогов | количество, начальные, конечные, ударные |
| Состав звуков | гласные, согласные; их близость (б-п, д-т, з-с) |
| Расположение совпадающих звуков | начало слова сильнее конца (потребитель запоминает начало) |
| Длина слова | близкая по длине = выше риск смешения |
| Транслитерация | «Аквамарин» / «Aquamarine» — фонетически сходные |
| Ударение | разное ударение снижает сходство, но не устраняет |

**Пример высокого фонетического сходства**: «ЛОМАРЕЛЬ» — «ЛОМАРАЛ» (совпадают 5 из 7 звуков, начало идентично, длина близкая).

### 2. Графическое (визуальное) сходство

| Признак | На что обратить внимание |
|---|---|
| Общий зрительный образ | первое впечатление при взгляде |
| Алфавит / шрифт | кириллица vs латиница — снижает сходство, но не устраняет |
| Расположение элементов | вертикаль/горизонталь, центр/край |
| Цветовая гамма | для комбинированных и изобразительных знаков |
| Изобразительные элементы | для логотипов — общая композиция, символика |
| Стилизация | курсив, заглавные, минимализм |

**Пример высокого графического сходства**: одинаковый логотип в красном круге vs логотип в красном круге с другим словом — высокая степень сходства комбинированного знака.

### 3. Семантическое сходство (смысловое)

| Признак | На что обратить внимание |
|---|---|
| Общее понятие, идея | «Лесная свежесть» — «Аромат леса» — близкая семантика |
| Перевод | «АктивЛайф» — «ActiveLife» — тождественная семантика |
| Род / вид | «Тигр» — «Хищник» — семантически связаны (род/вид) |
| Антонимия | антонимы могут быть **сходными** через противопоставление (рекламная тактика) |
| Уровень обобщения | конкретное vs абстрактное (например, «Ласточка» vs «Птица») |

**Пример высокого семантического сходства**: «Доктор Сильный» — «Профессор Здоровья» (близкая семантика «специалист по здоровью»).

### 4. Общий зрительный образ (интегральная оценка)

Финальная оценка целостного впечатления — то, как обычный потребитель воспринимает знак при кратком взгляде. **Доминирующие элементы** имеют больший вес, **второстепенные** — меньший.

**Доминирующие элементы**:
- словесные элементы в комбинированных знаках (всегда сильнее изобразительных);
- крупные / контрастные / центральные элементы;
- оригинальные / неожиданные.

**Второстепенные**:
- общеупотребительные слова (товар, услуга, ООО);
- цифры, символы технических характеристик;
- описательные элементы.

### Степени сходства

| Степень | Описание | Юридическое значение |
|---|---|---|
| **Тождество** | Полное совпадение всех элементов | Безусловный отказ в регистрации для однородных товаров (п. 6 ст. 1483 ГК РФ) |
| **Сходство до степени смешения** | Близость до степени, при которой средний потребитель может перепутать | Отказ в регистрации для однородных товаров |
| **Сходство (без степени смешения)** | Есть общие черты, но различия достаточно велики | Регистрация возможна |
| **Несходство** | Различия преобладают | Свободная регистрация |

**Принцип «гнущегося стержня»** (Пленум ВС № 10 п. 162): чем сильнее сходство обозначений, тем меньшая степень однородности товаров достаточна для отказа; и наоборот, чем более идентичны товары — тем меньшее сходство обозначений уже создаёт риск смешения.

## Однородность товаров и услуг

Оценивается отдельно от сходства самих обозначений.

### Источники

- **МКТУ (Международная классификация товаров и услуг)** — действующая редакция Ниццкой классификации `[ПРОВЕРИТЬ АКТУАЛЬНОСТЬ РЕДАКЦИИ]` (сверять по Роспатенту / ВОИС; на момент разведки 2026-06 фигурировала 11-я ред.); 34 класса товаров + 11 классов услуг = 45 классов;
- **Рекомендации Роспатента** по применению МКТУ;
- **Постановление Пленума ВС РФ № 10 от 23.04.2019 п. 162** — однородность определяется не только формальной принадлежностью к одному классу.

### Критерии однородности

| Критерий | Содержание |
|---|---|
| **Принадлежность к одному классу МКТУ** | Сильный, но не решающий фактор. Один класс ≠ автоматически однородные товары |
| **Природа товара** | Назначение, материал, способ изготовления |
| **Круг потребителей** | Общий потребитель, врачи, организации, дети |
| **Условия реализации** | Аптеки, супермаркеты, специализированные магазины, онлайн |
| **Взаимозаменяемость / взаимодополняемость** | Можно ли заменить один товар другим |
| **Совместное производство и продажа** | Производят ли одни и те же производители |

**Для фарм-компании**:
- **Класс 5** (фармацевтические препараты, БАД, ветеринарные препараты, диетические продукты) — основной;
- **Класс 3** (косметика, парфюмерия) — пересекается с БАД и медицинской косметикой;
- **Класс 10** (медицинские изделия) — пересекается с фарм. портфелем;
- **Класс 30** (пищевые продукты) — пересекается с БАД на пограничных категориях;
- **Класс 35** (реклама, продажа третьим лицам) — для торговых марок продавцов;
- **Класс 44** (медицинские услуги) — для клиник, аптек, телемедицины.

| **TMview (EUIPO)** | https://www.tmdn.org/tmview/ | ТЗ ЕС, государств-членов ЕС, ряда стран мира | Бесплатно: fuzzy search, поиск по изображению | По существу — для европейского фокуса |

### Стратегия использования WIPO-источников

**Двухступенчатая модель**:

1. **WIPO GBD Similar Name Search** (`/branddb/en/similarname`) — **первая ступень**:
   - Широкий fuzzy-search **по миру** — поиск всех потенциально похожих знаков в одном агрегаторе;
   - Получаем список «кандидатов» — потенциальных противопоставлений из любых баз (национальные, Мадрид, ЕС, US, и т. д.);
   - Преимущество: один запрос покрывает множество юрисдикций.

2. **WIPO Madrid Monitor** — **вторая ступень**:
   - Используется, когда в результатах GBD найден знак с обозначением «Madrid» / международной регистрации (IR-номер);
   - Даёт **актуальные** и **авторитетные** данные по этому конкретному Мадридскому знаку (статус, страны распространения, даты, классы, владельцы, последующие отказы национальных органов);
   - Преимущество: real-time, прямо из реестра WIPO.

**Когда какой источник**:
- Проверка по РФ (первичная) → **поисковая платформа Роспатента** (официальная, фонетика / семантика / нечёткий, включая общеизвестные ТЗ РФ);
- Кросс-проверка РФ и агрегатор с удобными карточками → **linkmark.ru**;
- Pre-filing screening на широком международном фронте → **GBD Similar Name**;
- Подтверждение / детальный анализ конкретного Мадридского знака → **Madrid Monitor**;
- Региональный фокус ЕС → **TMview**;
- Точный поиск по номеру РФ-регистрации → **ФИПС**.

### Алгоритм проверки

1. **Подготовить варианты обозначения** (5–10 формулировок):
   - точное название;
   - с переменой регистра / транслитерации;
   - с морфологическими вариантами (окончания, склонения);
   - с фонетическими заменами (б-п, з-с, у-ю);
   - с разбивкой / слитным написанием.

2. **Определить классы МКТУ**, в которых будет регистрироваться знак (типично для БАД-компании: 5, 3, 30, 35 — см. выше).

3. **Поиск по РФ**:
   - **Первичная — официальная платформа Роспатента** (`searchplatform.rospatent.gov.ru/trademarks`): вкладки ТЗ РФ / общеизвестные ТЗ РФ / международные ТЗ; режимы фонетический / семантический / нечёткий — один запрос покрывает вариации;
   - **Кросс-проверка — linkmark.ru**: точный поиск по названию и по каждому варианту из шага 1; при необходимости — по правообладателю (поиск ТЗ конкурентов); изображение — по Венской классификации (платно, ≈500–1000 ₽).

4. **Поиск в WIPO Global Brand Database — Similar Name Search** (международный фронт):
   - Fuzzy search по основному варианту обозначения через `/branddb/en/similarname`;
   - Фильтр по интересующим странам (РФ, ЕАЭС, ключевые экспортные рынки);
   - Фильтр по классам Ниццы;
   - Зафиксировать список кандидатов с IR-номерами (Мадридские) для второй ступени.

5. **Детальная проверка Мадридских регистраций через WIPO Madrid Monitor**:
   - Для каждого найденного на шаге 4 знака с обозначением «Madrid» / IR-номером — открыть в Madrid Monitor;
   - Получить актуальный статус (зарегистрирован / отозван / частично отказан в конкретных странах);
   - Зафиксировать перечень стран распространения, классы, владельца;
   - При наличии изображения — сверить через поиск по изображению (по концепции / форме / цвету).

6. **Дополнительная проверка** (по необходимости):
   - TMview — для углублённого анализа ЕС-регистраций;
   - USPTO TESS — для США (если планируется экспорт);
   - CNIPA — для Китая (если планируется экспансия);
   - ФИПС — точная сверка по конкретному РФ-номеру.

7. **Анализ результатов** по 4 критериям сходства (фонетика / графика / семантика / общий образ) для каждого найденного потенциального противопоставления.

8. **Однородность товаров** — сопоставить классы МКТУ найденных знаков с планируемыми классами.

9. **Сводный риск-отчёт** (см. шаблон ниже).

## Структура отчёта о проверке

**Каноническая структура отчёта — в `skills/trademark-search/SKILL.md`, раздел «Обязательная структура ответа» (единственный источник, чтобы не было дрейфа двух версий).** Здесь — только требования к **содержанию** аналитических разделов, которые skill заполняет из этой методики:

- **Раздел «Анализ каждого противопоставления»** — по каждому знаку: фонетика / графика / семантика / общий зрительный образ (см. «Критерии сходства» выше), затем однородность товаров **с указанием конкретных позиций МКТУ** (общие фразы «однородные товары» без расшифровки запрещены), затем совокупный риск (см. «Уровни риска» ниже). Для каждого знака — вывод «что делать».
- **Раздел «Рекомендация»** — ровно один из: ✅ подавать без правок / ⚠️ подавать с уточнениями (узкий перечень товаров/услуг) / ❌ не подавать в этой редакции (рассмотреть альтернативы) / 🔄 доработка (изменение обозначения / переговоры с правообладателем / опротестование).
- **Раздел «Заметка юристу / патентному поверенному»** — что проверено; что **не** проверено (общеизвестные ТЗ за пределами фона, фирменные наименования, региональные базы — конкретно); результат existence-check норм; что требует патентного поверенного; оставшиеся маркеры `[ПРОВЕРИТЬ ИСТОЧНИК]`, `[СТРАТЕГИЧЕСКОЕ РЕШЕНИЕ ЮРИСТА]`.

## Уровни риска (для совокупной оценки)

Используется аналогично основной шкале (см. `references/risk-scale.md`), но с поправкой на ТЗ-специфику:

| Уровень | Условие |
|---|---|
| **Блокирующий** | Тождество или очень высокое сходство по 3+ критериям + высокая однородность товаров (включая один и тот же класс МКТУ). Регистрация заведомо отказная |
| **Высокий** | Высокое сходство по 2 критериям + средняя/высокая однородность. Регистрация спорная, риск отказа экспертизы или возражения от правообладателя |
| **Средний** | Среднее сходство по 1–2 критериям или высокое по одному + средняя однородность. Возможны вопросы эксперта, но шанс регистрации есть |
| **Низкий** | Низкое сходство или различия преобладают. Регистрация вероятна |
| **Вопрос бизнесу** | Технически возможна регистрация, но коммерческий риск столкновения с известным брендом или ожидаемое возражение (например, у компании-гиганта) — решение о подаче за бизнесом |

## Что запрещено

- **Не давать категоричное юридическое заключение** «знак точно будет зарегистрирован» / «знак точно не будет зарегистрирован». Финал — за патентным поверенным и решением Роспатента.
- **Не выдумывать** реквизиты найденных ТЗ (номера регистраций, даты, классы); всё — по реальным результатам поиска.
- **Не оценивать однородность товаров** без указания конкретных позиций — общие фразы «однородные товары» без расшифровки запрещены.
- **Не игнорировать общеизвестные ТЗ** (даже если они не в основных базах) — фиксировать `[ПРОВЕРИТЬ ИСТОЧНИК]` отдельно.
- **Не подменять решение бизнеса** в категории «вопрос бизнесу».

## Маркеры

Общий реестр маркеров — `references/citation-rules.md`, «Реестр маркеров неполноты». Ниже — маркеры слоя «товарные знаки»:

- `[ПРОВЕРИТЬ ИСТОЧНИК]` — нужна проверка дополнительной базы или конкретного ТЗ;
- `[ПРОВЕРИТЬ ОБЩЕИЗВЕСТНОСТЬ]` — проверить, не входит ли ТЗ в перечень общеизвестных (ст. 1508 ГК РФ);

- `[ТРЕБУЕТСЯ ПАТЕНТНЫЙ ПОВЕРЕННЫЙ]` — задача за пределами screening; требует FTO-заключения.

## Автоматизация поиска

С 2026-06-02 поиск **автоматизирован** через:
- **`agent-browser`** (Vercel Labs) — для SPA / form-driven сайтов (поисковая платформа Роспатента, linkmark.ru, WIPO GBD);
- **`Tavily API`** — для extract карточек WIPO Madrid Monitor по IR-номерам и для фонового `/search` по общеизвестным ТЗ.

Полная техническая спецификация (URL-схемы, протоколы, CAPTCHA workflow, fallback-цепочки, парсинг результатов) — в `references/trademark-search-automation.md`.

**Skill `trademark-search` сам выполняет поиск** в базах РФ и международных:

| База | Метод | Стоимость |
|---|---|---|
| Платформа Роспатента (ТЗ РФ / общеизвестные / международные) | agent-browser (SPA; фонетика/семантика/нечёткий) | бесплатно, без логина |
| linkmark.ru (кросс-проверка РФ) | agent-browser (Chrome) | бесплатно |
| WIPO GBD Similar Name | agent-browser headed (CAPTCHA решается юристом 1 раз) | бесплатно |
| WIPO Madrid Monitor (карточки IR) | Tavily /extract | ~0.4 credit / карточка (Tavily free 1000/мес) |

Ручной режим — fallback при недоступности инструментов или при их сбое.

## Ограничения текущей методики (MVP)

1. **Поиск по изображениям не автоматизирован** — Венская классификация в linkmark — платно (500–1000 ₽); поиск по изображению WIPO GBD — ручной анализ через `image search`; в MVP проверяются только текстовые элементы.
2. **Fuzzy / фонетика / семантика** — есть на официальной платформе Роспатента (первичная РФ-база); в linkmark.ru отсутствует, поэтому для linkmark готовим 5–10 вариантов обозначения (см. шаг 1 алгоритма).
3. **CAPTCHA на WIPO GBD** — может потребовать ручного решения юристом 1 раз в начале сессии. После решения cookies сохраняются (`--session wipo-gbd`).
4. **Tavily не пробивает WIPO GBD** (Cloudflare). Используем только agent-browser.
5. **Madrid Monitor — точечные карточки**, не массовая выгрузка (запрещено ToS). IR-номера обнаруживаются через WIPO GBD на предыдущем шаге.
6. **Не проверяются**:
   - фирменные наименования (ЕГРЮЛ);
   - коммерческие обозначения;
   - доменные имена;
   - неохраняемые элементы общеизвестных брендов.
   Если нужно — отдельная задача.
7. **Версионирование протоколов**: при изменении вёрстки сайтов протоколы в `trademark-search-automation.md` потребуют актуализации (процедура — там же, §15).
