# Confidentiality Rules

Назначение: правила обращения с конфиденциальной информацией в проекте.

## Базовое правило

До отдельного решения юриста не использовать реальные:
- персональные данные (ФИО, паспортные данные, ИНН физических лиц, контакты, адреса);
- коммерческую тайну;
- содержание NDA / confidential документов;
- внутренние стратегические документы компании;
- содержание переписки с контрагентами и госорганами по конкретным делам.

## Что разрешено

- Гипотетические сценарии без указания реальных лиц и компаний.
- Обезличенные документы в слое образцов `legal-document-samples`.
- Ссылки на нормы, опубликованные судебные акты, официальные разъяснения.
- Реквизиты собственной компании только в составе подготовленного документа, если юрист явно дал такую вводную.

## Обезличивание для слоя образцов

**Полная методика, плейсхолдеры и шаблоны скриптов** — см. `references/anonymization-procedure.md`. Это закреплённый порядок, использовавшийся при полном обезличивании `examples/` 2026-05-28.

Краткая сводка плейсхолдеров (применяется по ролям):

- **Стороны (роли)**: `[НАИМЕНОВАНИЕ_ПОКУПАТЕЛЯ]` / `[НАИМЕНОВАНИЕ_ПОСТАВЩИКА]` / `[НАИМЕНОВАНИЕ_ЗАКАЗЧИКА]` / `[НАИМЕНОВАНИЕ_ИСПОЛНИТЕЛЯ]` / `[НАИМЕНОВАНИЕ_ЛИЦЕНЗИАРА]` / `[НАИМЕНОВАНИЕ_ИСТЦА]` / `[НАИМЕНОВАНИЕ_ОТВЕТЧИКА]`; своя организация — `[НАИМЕНОВАНИЕ_ОРГАНИЗАЦИИ]` / `[ORGANIZATION_NAME]`.
- **Физические лица**: `[ФИО_ГЕНДИРЕКТОРА]` / `[ФИО_ПРЕДСТАВИТЕЛЯ]` / `[ФИО_ИСПОЛНИТЕЛЯ]` / `[ФИО_СОТРУДНИКА]` / `[ФИО_ЗАСТРАХОВАННОГО_ЛИЦА]` / `[ФИО_ДОЛЖНОСТНОГО_ЛИЦА_ОРГАНА]`.
- **Реквизиты**: `[ОГРН]` / `[ИНН]` / `[КПП]` / `[АДРЕС_ОРГАНИЗАЦИИ]` / `[АДРЕС_СУДА]` / `[АДРЕС_ОРГАНА]`.
- **Банковские**: `[НАИМЕНОВАНИЕ_БАНКА]` / `[РАСЧЁТНЫЙ_СЧЁТ]` / `[SWIFT]` / `[IBAN]` / `[INTERMEDIARY_BANK]`.
- **Документы**: `[НОМЕР_ДОГОВОРА]` / `[НОМЕР_ДОВЕРЕННОСТИ]` / `[НОМЕР_ДЕЛА]` / `[НОМЕР_ПОСТАНОВЛЕНИЯ]` / `[НОМЕР_РУ]` / `[НОМЕР_СЕРТИФИКАТА]` / `[UUID_ОБРАЩЕНИЯ]`.
- **Контакты**: `[EMAIL]` / `[ТЕЛЕФОН]`.
- **Суммы**: `[СУММА_РУБ]` / `[СУММА_USD]` / `[СУММА_EUR]` / `[СУММА_CNY]`.

**Что НЕ обезличиваем**: даты, наименования продуктов, нормы права, общие географические указатели, общие названия госорганов, жанровые заголовки, стандартные клаузы.

**Исключение по суммам**: в отзывах на иск и отзывах на апелляционную жалобу суммы сохраняются — методика отзыва основана на расчётах.

Карточка примера (см. `templates/sample-prep/example-card-template.md`) обязательна: что обезличено, что переиспользуемо, что нельзя копировать.

## Запреты

- Нельзя помещать в репозиторий или в подсказки реальные подписанные документы.
- Нельзя приводить реальные цитаты сотрудников компании без согласования.
- Нельзя приводить реальные тексты переписки с контрагентом и госорганом.
- Нельзя передавать содержание NDA / confidential документов через примеры.

## Если документ нужен для разбора

Если для решения задачи нужен конкретный реальный документ:
- юрист может приложить его в сессии (а не в репозитории);
- содержимое не попадает в слой образцов `legal-document-samples` без обезличивания;
- по завершении задачи содержимое не цитируется в будущих документах.

## Маркер чувствительности

Если данные потенциально чувствительные, но юрист всё же передал их в сессию — фиксировать в результате пометку:
> «В работе использованы данные конкретного дела. Файл подготовлен как черновик и не предназначен для повторного использования как образец.»
