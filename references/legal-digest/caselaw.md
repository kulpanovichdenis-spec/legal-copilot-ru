# Практика в дайджесте

Читать после `references/legal-digest/method.md` для `SINGLE_CASE` и `CASELAW_TREND`.

Здесь анализируются переданные акты или подборка другого агента. Дополнительный поиск актов — отдельная задача `skills/case-law-search/SKILL.md` по `references/case-law-search.md`; не запускать его вместо обзора пакета. Полный разбор одного акта — `references/court-decision-analysis.md`. Здесь только единица дайджеста. Реквизиты акта (суд, дата, номер дела) не показывать, пока первоисточник не открыт.

К полям карточки из `method.md` добавить:

```yaml
issue: ""
decisive_facts: []
holding: ""          # COURT_HOLDING
reasoning: ""        # COURT_REASONING, если нужен для переноса
procedural_status: ""
operative_act: ""    # какой акт линии сейчас имеет значение
later_history: ""
limits: []
contrary: ""         # для тренда: противоположная линия или «в обозрении нет»
```

`COURT_HOLDING` и `COURT_REASONING` не смешивать с `SYNTHESIS` и с комментарием автора.

## SINGLE_CASE

Сначала вопрос, минимум решающих фактов, холдинг или тест и процессуальный статус. Потом практическое значение. Переносимый тезис не выводить из того, кто выиграл. Доводы стороны писать только если без них тезис нечитаем.

## Линия одного спора

Один спор — одна линия: первая инстанция → апелляция → кассация → Верховный Суд или надзор → текущий статус.

Зафиксировать, где менялась мотивировка, какой акт сейчас рабочий, отменён ли нижестоящий, изменила ли поздняя проверка значение ранней мотивировки. Инстанции одного спора не считать независимыми подтверждениями.

## Переносимый тест

Предпочитать схему «вопрос → тест → решающие факторы → пределы → результат». Для многофакторной оценки сохранить факторы, без которых тест не применить к новому делу. Аналогия держится на вопросе и решающих фактах, не на внешнем сходстве сюжета. Если аналогия всё же нужна в тексте — маркер `[ПРИМЕНЯЕТСЯ ПО АНАЛОГИИ: X→Y, отличие Z]`.

## CASELAW_TREND

Модель: вопрос → кандидат в тезис → поддерживающие линии → противоположные → различающие факты → вес → устойчивость во времени → синтез → пределы.

- Проверить в пакете противоположные исходы и мотивировки. Если их нет и дополнительного исследования не было, прямо указать границы подборки; не утверждать, что противоположной практики не существует. Необходимость дополнительного поиска вынести юристу как отдельный пробел.
- Разные исходы объяснять фактами или условиями, а не «суды расходятся» без разбора.
- Повтор одной формулы по цепочке цитирования не умножает авторитет.
- Неполный набор так и называть: «в пределах обозреваемых дел».
- «Единого подхода нет» — только при реальной противоположной линии, не при двух случайно разных актах.
- Связь позиции с нормой утверждать после `list_position_norm_links`.

## Проверка текста о практике

Отдельным проходом после черновика:

- суд, инстанция, дата и номер дела сверены с открытым актом;
- текущий статус и дальнейшая история не потеряны;
- довод стороны, мотивировка нижней инстанции и итоговый холдинг разделены;
- решающие факты на месте;
- назван правовой вопрос, а не сюжет;
- холдинг не выведен только из исхода;
- отменённый акт не подан как текущий авторитет;
- инстанции одного спора не посчитаны как несколько независимых опор;
- при заявлении о тенденции противоположные линии проверены в пакете, границы подборки названы; отсутствие отдельного поиска не скрыто;
- синтез не вложен в уста суда;
- сила и устойчивость линии не завышены;
- аналогия опирается на вопрос и факты, не на похожие слова.
