# 15. Доказательства и восприятие: как ФАС обосновывает вывод

Карточка рекламного плейбука. Вход, алгоритм и ограничения базы — `references/ad-creative-playbook.md` (индекс). Подгружать только сработавшие карточки, не весь реестр.

Методологический раздел — помогает агенту предсказать, чем ФАС будет доказывать нарушение, и что запросить у бизнеса для защиты.

**Инструменты ФАС по практике из базы**:
- **лингвистический анализ** по толковым словарям: семантика слова решает («факт» = заверение — «Лизобакт», docId `32c0456b`; исторически «реагирование» ≠ «действие» — «Аципол» `[ПРОВЕРИТЬ ИСТОЧНИК]`); вид глагола (совершенный/несовершенный) — базовый маркер гарантии результата;
- **оценка совокупности элементов**: текст + видеоряд + аудиоряд + контекст размещения (ключевые слова конкурента — JustFood, docId `b059ecfb`);
- **фактические замеры**: количество слов сноски против секунд показа (Россельхозбанк, docId `6f76e699`); доля площади текста предупреждения (не заливки — docId `45fc5e1e`); состав «100% площади» поста = текст + изображения (docId `1d21058a`);
- **инструкция по применению** как эталон достоверности для ЛС (карточки 2–4);
- **социологические опросы**: позиция центрального аппарата ФАС — даже мнение меньшинства респондентов (порядка 20–30%) о восприятии гарантии/сравнения учитывается; суды подходят к мнению меньшинства осторожнее `[ПРОВЕРИТЬ ИСТОЧНИК: практика 2011–2017 вне локальной базы; при споре запросить свежую практику]`.

**Что агент рекомендует бизнесу собирать заранее**: подтверждение каждого фактического утверждения (исследования с датой и источником), инструкция/регудостоверение, обоснование критерия любых «№1/лучший», макеты с замером площадей предупреждений.
