# CL-3. ВАС survival check

Карта case-law-search. Индекс — `references/case-law-search.md`. Подгружать, когда среди источников есть позиция ВАС (Пленум, Президиум, информ. письмо, обзор).

**Правило (§11, §31.6).** Не применять простую лестницу «ВС > ВАС». Сохраняющая силу/значение позиция ВАС остаётся **high authority**, пока не преодолена изменением законодательства либо последующей позицией ВС. **Возраст позиции и прекращение существования ВАС сами по себе вес не понижают.**

**Survival check для значимой позиции ВАС (§11.1):**
1. Какой это тип акта (Пленум / Президиум / информ. письмо / обзор)?
2. Сохраняет ли силу/значение?
3. Не изменилась ли релевантная норма?
4. Есть ли более поздняя позиция ВС по тому же issue?
5. Совместимы ли позиции?
6. Если несовместимы — единична новая позиция ВС или сформирована новая линия?
7. Как последующая практика воспринимает позицию ВАС?

**Статусы:**

```
CURRENT
SUPERSEDED
PARTIALLY_SUPERSEDED
QUESTIONABLE_AFTER_LAW_CHANGE
CONFLICT_WITH_LATER_SC
HISTORICAL_ONLY
```

**Логика конфликта (§11.2):**
- новый Пленум ВС прямо заменил подход ВАС → применяется новый подход ВС (`SUPERSEDED`);
- изменился закон, основание старой позиции исчезло → `QUESTIONABLE_AFTER_LAW_CHANGE`, провести current-law analysis;
- **единичное** содержательное определение СКЭС конфликтует с сохраняющим силу Пленумом ВАС → **не** объявлять ВАС автоматически устаревшим; зафиксировать `CONFLICT_WITH_LATER_SC` (high-authority conflict) и продолжить targeted search последующей практики.

**Выход в классификатор.** Флаг `a1/a2/a4` для `tools/case_law/practice_status.py` ставится `True` только при статусе `CURRENT` (или `PARTIALLY_SUPERSEDED` в непреодолённой части). При `SUPERSEDED`/`HISTORICAL_ONLY` позиция ВАС в established-set не идёт. `CONFLICT_WITH_LATER_SC` — не established автоматически: вынести как high-authority conflict юристу и продолжить поиск.
