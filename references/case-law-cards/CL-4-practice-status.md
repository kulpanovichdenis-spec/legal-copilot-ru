# CL-4. Статус практики: критерии и подсчёт

Карта case-law-search. Индекс — `references/case-law-search.md`. Ключевая карта: присваивает очищенному пулу кандидат-статус **сформированной/устоявшейся практики**. Готовность завершить текущий проход проверяется отдельно по CL-7.

**Термин «сформированная практика» — не синоним нескольких похожих дел (§31.9).** Применять строго по критериям ниже.

**Сформированная практика есть, если (§13.1):**
- **Вариант 1** — есть A1, A2 или A4 по issue;
- **Вариант 2** — ≥2 согласованных содержательных определения СКЭС (A3) по одному legal issue;
- **Вариант 3** — 1 содержательное определение СКЭС + ≥3 согласованных кассационных округа, реально применяющих тот же подход;
- **Вариант 4** — при отсутствии A1–A4 подход поддерживают **более половины** кассационных округов, реально высказавшихся по тому же issue → **устоявшаяся преобладающая кассационная практика**.

**Подсчёт — по округам, а не по числу решений (§13.2, §31.10).** `1 округ = 1 позиция` для cross-circuit counting. Много решений внутри одного округа показывают лишь стабильность его собственной позиции, но доп. «голосов» не дают. До подсчёта CL-7 отделяет инстанции одного спора, копирующий lineage и самостоятельное применение. Считать только решения: по тому же issue, при сопоставимом регулировании, реально применяющие тот же подход. Одинаковый исход по иной норме/основанию — не подтверждение. Внутриокружный split остаётся видимым и требует оценки, а не произвольного одного «голоса».

**Consistency (§13.1):** есть противоположные округа → `SPLIT_WITH_MAJORITY` (нельзя называть практику единообразной); нет → `UNIFORM_CASSATION_PRACTICE`.

**Словарь статусов (§14):** `SINGLE`, `REPEATED`, `LOCAL_STABLE`, `CROSS_CIRCUIT_TREND`, `HIGH_COURT_POSITION`, `ESTABLISHED_PRACTICE`, `ESTABLISHED_MAJORITY_PRACTICE`, `SPLIT`. Примеры: несколько актов одного округа → максимум `LOCAL_STABLE`; несколько округов в одну сторону, но <50% охвата → `CROSS_CIRCUIT_TREND`; один содержательный акт ВС без подтверждения → `HIGH_COURT_POSITION`, не `ESTABLISHED_PRACTICE`.

**Счёт и пороги — детерминированный тул, не проза.** После того как агент по CL-2/CL-3 определил уровни актов, отсеял отказные (§10 X) и решил, какие округа реально применяют подход, — подать структурированный вход в классификатор:

```bash
python tools/case_law/practice_status.py classify --skes 1 --circuits-support 3
python tools/case_law/practice_status.py classify --circuits-support 4 --circuits-oppose 2
```

Он вернёт `status` / `consistency` / `established` по §13. `established=True` позволяет остановить добор однотипных подтверждающих актов. Это не означает, что проверены later history, режим права, issue fit, сильная противоположная линия и применимость вывода. Эти проверки и outcome текущего прохода — CL-7 / `research_check.py`. **Выход классификатора — кандидат-статус для юриста, не окончательный вывод**; квалификацию актов и допустимый counted-set формирует агент, тул только считает и применяет прежние пороги.
