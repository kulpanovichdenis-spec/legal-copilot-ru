# CL-2. Иерархия authority судебных актов

Карта case-law-search. Индекс — `references/case-law-search.md`. Это методологическая модель веса актов; при работе сверять с `references/source-hierarchy.md` и не дублировать её.

**Authority ≠ похожесть ≠ forum relevance ≠ argumentative value** (§31.5). Здесь — только authority (юридический вес источника). Похожесть фактов — CL-6; своя кассация/прогноз — CL-5; качество мотивировки — CL-6.

**Лестница (§10):**

| Ур. | Что входит | Вес |
|---|---|---|
| **A1** | Постановления Пленума ВС; сохраняющие силу Пленумы ВАС | высший; возраст позиции ВАС сам по себе вес не снижает (см. CL-3) |
| **A2** | Позиции Президиума ВС; утверждённые Президиумом обзоры ВС; сохраняющие силу Президиумы ВАС | высокий |
| **A3** | Содержательные определения судебных коллегий ВС по существу (прежде всего СКЭС) | сильный; **одно** определение ≠ сформированная практика; несколько согласованных → могут её образовать (CL-4) |
| **A4** | Сохраняющие значение информ. письма Президиума ВАС, обзоры ВАС, аналогичные high-authority материалы ВАС (статус подтверждён) | высокий |
| **B1** | Арбитражные кассационные суды округов | все округа равны; «своя кассация» юридически не сильнее (CL-5) |
| **B2** | Апелляционные суды | substantive authority и источник аналогий, особенно если выше практики нет |
| **B3** | Первая инстанция | фактические аналоги, редкие конструкции, понимание применения; множество решений ≠ сформированная практика |

**X — отказные определения ВС/ВАС (§10 X, §31.7).** По умолчанию **исключать из substantive authority set**, если есть содержательная практика уровня апелляции и выше. **Нельзя** писать «Верховный Суд сформулировал позицию…» со ссылкой на отказное. Допустимо только: навигация, поиск терминологии, восстановление процессуальной истории, слабый сигнал при почти полном отсутствии содержательной практики — с явной оговоркой о процессуальной природе и ограниченном весе.

**Выход в классификатор.** Эта карта даёт вход для `tools/case_law/practice_status.py`: наличие действующих A1/A2/A4 (флаги `a1/a2/a4`), число согласованных A3 (`skes`), а отказные из подсчёта исключаются здесь, до вызова. Действующесть позиции ВАС — через CL-3.
