# Визуализация бюджета

Основной управленческий вид — один HTML-файл из `tools/legal_budget/render_html.py`. Цифры только из `view_model.json`. Помесячные суммы и мост «прошлый период → предложение» показываются таблицами. Внешние CDN, шрифты и трекеры не подключать. Конфиденциальные цифры наружу для построения графика не отправлять.

Рядом с существенной цифрой — что изменилось, почему, что решить. Компонент без данных не рисовать.

Записка CFO — `.docx`. Книга — `.xlsx`. Оба читают тот же view model. Сверка — `tools/legal_budget/reconcile.py`.

Если страница не открывалась в браузере, в `output/render_meta.json` остаётся `visual_qa_performed: false`. Не писать, что вид проверен глазами.
