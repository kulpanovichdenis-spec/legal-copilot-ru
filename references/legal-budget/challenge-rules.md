# Правила challenge

Скрипт `tools/legal_budget/challenge.py` возвращает находки с id, серьёзностью, правилом, ссылками, смыслом, действием и признаком блокировки. Текст модели этот список не заменяет.

Минимум, который фикстура обязана ловить:

- `annual_mismatch` — год не равен сумме месяцев;
- `missing_provenance` — существенная строка без источника и без допущения;
- `accrual_double_count` — один invoice id в факте и в начислении;
- `one_off_carried` — закрытое разовое перенесено дальше без тега;
- `allocation_as_saving` — смена центра затрат подана как экономия;
- `headcount_external_inconsistent` — штат вниз, внешние расходы те же, хотя работу перенесли наружу.

Находка не правит бюджет сама. Исправление — новое состояние и повторный прогон.
