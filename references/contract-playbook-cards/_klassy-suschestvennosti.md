# Классы существенности/заключённости — легенда

Общая легенда для всех карточек `references/contract-playbook-cards/`. Слой проверки условий договора на соответствие требованиям закона и доктрины; дополняется по мере необходимости.

- **F1 — обязательно для заключённости** (`F1_FORMATION_REQUIRED`): условие должно быть согласовано/определимо для заключенности; перед выводом о незаключенности проверить весь contract package и поведение сторон
- **F2 — существенно для доктрины, восполнимо диспозитивной нормой** (`F2_MATERIAL_DEFAULTABLE`): существенно для содержания/доктрины, но пробел может восполняться диспозитивной нормой; отсутствие в тексте != автоматическая незаключенность
- **F3 — стало существенным по заявлению стороны** (`F3_PARTY_ELEVATED`): условие стало существенным, потому что сторона заявила необходимость его согласовать; диспозитивный default не заменяет достигнутое соглашение
- **M — предписано законом (не равно заключённости)** (`M_STATUTORY_CONTENT`): закон требует включить/раскрыть/зафиксировать условие; не конвертировать в F1 без нормы/практики о заключенности
- **Q — признак квалификации договорного типа** (`Q_TYPE_FORMING`): признак квалификации договорного типа; отсутствие может вести к переквалификации, а не обязательно к незаключенности
- **V — требование формы** (`V_FORM`): требование формы
- **V — условие действительности/ничтожности/оспоримости** (`V_VALIDITY`): условие действительности/ничтожности/оспоримости
- **R — эффект регистрации/публичности** (`R_REGISTRATION_EFFECT`): регистрация/публичность влияет на возникновение/переход/противопоставимость права или предоставления, отдельно от formation
- **C — коммерчески критично, без автоматического formation-следствия** (`C_COMMERCIAL`): коммерчески критичное условие без автоматического formation consequence
- **X — отраслевой overlay (приоритет для конкретной модели)** (`X_SECTOR_OVERLAY`): специальное отраслевое регулирование может добавлять F1/M/V/R и имеет приоритет для конкретной модели
- **⚠️ CLASSIFIER EXCLUSION — не квалифицировать как обычный двусторонний договор** (`CLASSIFIER_EXCLUSION`): смежный институт не должен насильно классифицироваться как обычный двусторонний договор
