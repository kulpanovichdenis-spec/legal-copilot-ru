# Опционный договор

Короткая карточка прежнего плейбука, перенесена 10.11.2026 без переработки: только правовая база, классы условий и правило проверки. Разделов о подготовке договора и спорах нет. Статьи ГК, названные в карточке, сверены 10.11.2026 по К+. Черновой рабочий материал для юриста.

**Карточка используется только для discovery/navigation и не подтверждает действующую редакцию или дословный текст нормы. Перед правовым выводом вызвать `route_norm_verification(jurisdiction="RU", probe=true)`, открыть полный текст только по маршруту с `usable_now: true` и проверить редакцию, статус, pinpoint и provenance; если такого маршрута нет — поставить `[ПРОВЕРИТЬ НОРМУ]`**

## 1. Откуда берутся правила

ст. 429.3 ГК РФ.

## 2. Проверка договора

Классы условий (легенда — `references/contract-playbook-cards/_klassy-suschestvennosti.md`).

**F1 — обязательно для заключённости (или определимо)**:
- Действия/исполнение, которое управомоченная сторона вправе потребовать; механизм требования должен позволять определить содержание исполнения.

**Правило проверки.** Для автоматической проверки отсутствие срока — жёлтый уровень и проверка юристом, а не автоматический красный без анализа текста и практики.
