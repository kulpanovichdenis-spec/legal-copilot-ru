# Карта соответствия полей (Field Mapping)

Карта обязательна при подготовке документа по образцу с подстановкой объективных данных. Один документ — одна карта. Карта составляется **до** подстановки.

См. правила: `references/template-filling-rules.md`.

## 1. Документ

Тип документа, под который заполняется карта (например: ходатайство об оплате штрафа, ДС № N к договору № X, претензия по договору поставки).

## 2. Образец

- Имя файла и расположение образца.
- Дата образца / источник.
- Что из образца считается **формой** (структура + стандартные формулировки).
- Что из образца считается **образцовыми данными**, которые подлежат замене.

## 3. Первоисточники

Перечислить все документы-первоисточники, из которых берутся объективные данные:

| № | Источник | Что в нём | Дата | Объём | Где находится |
|---|----------|-----------|------|-------|----------------|
| 1 |          |           |      |       |                |
| 2 |          |           |      |       |                |

## 4. Таблица полей

| № | Поле в образце | Значение в образце | Первоисточник | Значение из источника | Подставленное значение | Сверено с другим источником | Статус |
|---|----------------|---------------------|---------------|------------------------|------------------------|------------------------------|--------|
|   |                |                     |               |                        |                        |                              |        |

Колонка «Статус»: `сверено` / `подставлено без сверки` / `требует проверки` / `несовпадение`.

## 5. Сверка пересечений

Перечислить поля, которые встречаются в нескольких источниках. По каждому полю отметить, совпали ли значения. Несовпадение фиксировать маркером `[ПРОВЕРИТЬ СООТВЕТСТВИЕ ИСТОЧНИКОВ]` и не подставлять до выяснения.

| Поле | Источник 1 | Значение 1 | Источник 2 | Значение 2 | Совпадает | Действие |
|------|------------|------------|------------|------------|-----------|----------|

## 6. Серия документов (если применимо)

Если по одному образцу готовится серия документов, перечислить:

- сколько документов в серии;
- какой первоисточник у каждого документа;
- проверка, что поля не унаследовались из соседнего документа в серии.

## 7. Что осталось проверить юристу

Поля, по которым сверка не доведена до конца:

- поле / источник / причина (нет доступа, требует уточнения, противоречие).
- маркеры по каждому: `[СВЕРИТЬ С ПЕРВОИСТОЧНИКОМ]` / `[ПРОВЕРИТЬ СООТВЕТСТВИЕ ИСТОЧНИКОВ]` / `[ПРОВЕРИТЬ РЕКВИЗИТЫ]` / `[СТРАТЕГИЧЕСКОЕ РЕШЕНИЕ ЮРИСТА]`.

## 8. Итог

Краткая запись: «Подготовлено N документов. Объективных полей — M. Сверено — K. Маркеры — указать какие и где.»
