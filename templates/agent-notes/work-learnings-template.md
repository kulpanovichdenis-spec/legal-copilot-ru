# Work Learnings — шаблон для logs/work-learnings.md

**Этот файл — шаблон в `templates/`** (коммитится в git). При первой work-сессии скопировать его в `logs/work-learnings.md` (тот gitignored), затем дополнять реальными записями.

```powershell
# Создать рабочий журнал на новой машине / при первой записи:
Copy-Item templates/agent-notes/work-learnings-template.md logs/work-learnings.md
```

Реальный файл `logs/work-learnings.md` содержит обозначения / реквизиты / детали реальных задач.
Обезличенные уроки переносятся в соответствующие reference / playbook.

## Назначение

Конечный шаг каждой **work-сессии** — короткая запись здесь:
- что было задачей;
- что прошло хорошо (skill отработал, методология выручила);
- что прошло плохо (skill не справился / выдал плохой черновик / методология не покрыла случай);
- какой урок закрепить в reference / SKILL / playbook;
- следующий шаг (если задача не закрыта).

В **dev-сессиях** этот файл прочитывается раз в неделю / по накоплению:
- закрытые уроки → переносим в правки reference / SKILL (обезличив);
- запись с пометкой «УРОК ЗАКРЕПЛЁН в playbook X.Y» можно удалять / архивировать.

## Формат записи

Каждая запись — отдельный раздел `## YYYY-MM-DD — Короткое название задачи`.

```markdown
## 2026-MM-DD — [Короткое название задачи]

**Задача**: [что нужно было сделать]
**Skill / инструмент**: [какой использовался, например trademark-search / gov-response / fas-ad-practice-search]
**Среда**: Claude Code / Cowork
**Результат**: [готово / черновик передан юристу / прервано]

### Что прошло хорошо
- ...

### Что прошло плохо
- ...

### Урок — что закрепить
- [ ] В `references/X.md` раздел Y — добавить [конкретное правило]
- [ ] В `skills/Z/SKILL.md` — расширить триггеры
- [ ] В playbook раздел N.M — добавить пример / уточнение
- [ ] Нужен новый файл / навык: ...

### Маркеры для dev-сессии
- `[ОБЕЗЛИЧИТЬ И В test-results]`
- `[ПРОПИСАТЬ В CLAUDE.md]`
- `[РАСШИРИТЬ TEST CASE]`
- `[ОБСУДИТЬ ПОЗИЦИЮ С ЮРИСТОМ]`

### Статус
- [ ] открыто
- [ ] урок закреплён в [файл / раздел]
- [ ] обезличено и перенесено в test-results
- [ ] можно архивировать
```
