# Test Case

## Название теста

## Skill / agent
Какой skill или agent тестируется.

## Входные данные
Что подаётся на вход: обезличенный документ, постановка задачи, дополнительные вводные. Если используются образцы из слоя `legal-document-samples` — указать их sample_id.

## Ожидаемый результат
Какие разделы должны быть в ответе, какие риски / вопросы / правки должны появиться, какие маркеры обязательны.

## Критерии оценки
- Не выдумывает факты.
- Не выдумывает нормы и судебную практику.
- Соблюдает стиль (`references/house-style.md`).
- Соблюдает иерархию источников и правила цитирования.
- Использует маркеры для непроверенного.
- Находит ключевые риски / слабые места.
- Не задаёт лишних вопросов.
- Даёт practically useful результат.
- Использует IRAC там, где нужно.
- Не подменяет решение юриста.
- Не маркирует результат как «финальный».

## Фактический результат
Что фактически вернул skill / agent. Скопировать ключевые блоки или приложить файл с полным ответом.

## Оценка
