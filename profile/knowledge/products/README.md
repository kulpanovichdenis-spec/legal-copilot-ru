# products/ — материалы по продуктам

Кладите инструкции, спецификации, СГР/РУ, макеты в `_inbox/`. Единый watcher
без LLM извлечёт текст, перенесёт оригинал в `originals/` и создаст черновик в
`cards/` со статусом `needs_enrichment`. В следующей сессии `knowledge-intake`
структурирует карточку.

Свойства продукта берутся из карточки; рекламный skill ищет её здесь по
`name`/`aliases`. Чего нет в источнике — маркер, а не догадка. Контент не коммитится.

Соглашение и схема карточки — `references/profile-knowledge-layer.md`.
