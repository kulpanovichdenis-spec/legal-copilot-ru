# brand/ — фирменный стиль компании

Скопируйте сюда, в `_inbox/`, папку фирменного стиля своей компании целиком
(бланки писем .docx/.dotx, логотипы, подписи — как выдал работодатель).
Затем агент выполнит `python -m tools.brand_kit scan`: папка переедет в
`originals/`, а в `brand.yaml` появится черновик описания бланков (что где
заполнять). После сверки и вашего подтверждения (`status: confirmed`) письма
контрагентам и ответы госорганам собираются сразу на бланке.

В git попадает только этот README и пустая `_inbox/`. Бланки, `brand.yaml` и
превью остаются в профиле и в репозиторий не коммитятся.

Правила — `references/brand-letterhead.md`.
