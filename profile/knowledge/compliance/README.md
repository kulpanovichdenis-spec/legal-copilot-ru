# Company compliance knowledge

Конфиденциальный слой внутренних политик компании. Содержимое не коммитится.

- `_inbox/` — новые документы для единого watcher;
- `originals/` — исходники после локального извлечения;
- `cards/documents/` — draft-карточки документов;
- `cards/rules/` — атомарные rule-карточки после `knowledge-intake`;
- `manifest.yaml` — покрытие, версии и пробелы;
- `index/company_compliance.sqlite` — перестраиваемый read-only индекс.

Оригиналы и карточки — источник истины. SQLite — только навигация. Статус
`verified` присваивает юрист. Нулевая выдача не доказывает отсутствие правила.
