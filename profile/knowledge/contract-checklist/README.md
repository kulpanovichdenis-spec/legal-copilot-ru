# Корпоративный чек-лист договоров (личный слой)

Короткий набор внутренних требований компании к договорам: по сути сжатый переговорный
плейбук для одного действия Word «Проверка чек-лист» (skill `word-contract-checklist`).
Содержимое папки — данные компании; в репозиторий попадает только этот README.

## Файлы

- `word-contract-checklist.md` — сами проверки: идентификатор, уровень (`critical` /
  `advisory`), формулировка требования. Разделы по видам договоров (юрлица, физлица,
  нерезиденты и т. п.) и общие правила: что считать шаблоном, как читать плейсхолдеры
  обезличивания, когда ставить `needs_review`.
- `contract-checklist-response-schema.md` — JSON-схема ответа. Перечень `checkId`
  в схеме совпадает с идентификаторами проверок из чек-листа: каждая проверка
  возвращается ровно один раз и в порядке перечня.

Меняя набор проверок, правьте оба файла вместе. Реквизиты своей компании и прочие
точные значения держите только здесь, не в базовых `references/`.

Без этих файлов действие «Проверка чек-лист» недоступно: Word-надстройка проверяет их
наличие (`requiredFiles` в её `actions.yaml`) до запуска.
