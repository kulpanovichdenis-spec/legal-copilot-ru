# corporate/ — корпоративные документы лица

Кладите устав, доверенности, решения ЕИО/участников, приказы о назначении в
`_inbox/`. Единый watcher без LLM извлечёт текст, перенесёт оригинал в
`originals/` и создаст черновик в `cards/` со статусом `needs_enrichment`.
В следующей сессии `knowledge-intake` выполняет структурирование. Производный
слой `entities/` корпоративного управления входным каналом не является и
watcher его не сканирует.

Соглашение и схема карточки — `references/profile-knowledge-layer.md`.
Профиль компании и правила из устава ведёт skill `charter-review` в подпапке `entities/<slug>/` (в `.gitignore`); данные из решений участников и приказов попадают туда же.
Чего нет в источнике — маркер, а не догадка. Контент не коммитится.
