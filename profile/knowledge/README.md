# profile/knowledge/ — персональный слой знаний

Карточки переиспользуемого знания, привязанного к первоисточнику. Контент —
в `.gitignore` (конфиденциально, едет с профилем через `tools/profile/portable.py`);
в git — только скелет (пустые папки + README).

- `products/`   — знания о продуктах (свойства, состав, показания, регистрация).
                  Потребитель: рекламный skill (`fas-ad-practice-search`).
- `corporate/`  — корпоративные документы конкретного лица (устав, доверенности,
                  полномочия подписантов, ЕИО, структура). Потребитель: будущие
                  корпоративные skills.
- `compliance/` — конфиденциальные внутренние политики: оригиналы, карточки
                  документов, атомарные rule-карточки и производный локальный индекс.
- `ip/`         — реестр товарных знаков: выгрузка в `_inbox/` → `catalog.html` (каталог)
                  и `index/` (для агента). Правила — `references/ip-registry-layer.md`.
- `case-studies/` — обезличенные карточки прошлых претензионных и судебных дел.
                    Они сохраняют контекст и provenance, но сами не являются
                    правовым основанием и не попадают в runtime как правила.
- `candidates/ verified/ superseded/` — общий слой knowledge objects (roadmap),
  с доменами `products/`/`corporate/` не смешивается.

Как это работает и схема карточки — `references/profile-knowledge-layer.md`.
Правила case-derived слоя — `references/case-knowledge-layer.md`.
