# Образцы документов (личный слой знаний)

Домен слоя знаний профиля: обезличенные образцы целых документов (договоры, ДС,
протоколы, иски, ответы госорганам, документы КоАП и т. п.) как источник **формы и
структуры**. Персональный слой — содержимое в `.gitignore`, не пушится, переносится
с профилем. Общего базового набора в репозитории нет.

## Структура

- `_inbox/` — поддерживаемый вход единого watcher: исходник переносится в закрытый staging внутри `workflow/_watcher/`, локально обезличивается (профиль `sample`: стороны, имена, реквизиты, контакты, суммы маскируются; предмет, даты, страны остаются) и ставится в очередь на карточку-разбор.
- `cards/<категория>/` — карточки-образцы `.md` (разбор: структура, приёмы, применимость) по категориям:
  `contracts` / `amendments` / `litigation` / `koap` / `gov-responses`.
- `originals/<категория>/` — исходный документ образца по тому же `<slug>`: читаемый
  `<slug>.md` (markitdown-рендер); у мигрированных образцов рядом эталонный `<slug>.docx`,
  у новых (через `sample-intake`) — только `.md`. Это источник **фактического текста**
  пунктов и внутренней структуры для адаптации. Overview-карточки (сводки группы документов)
  оригинала не имеют.

> ⚠️ Оригиналы обезличены **частично** — могут содержать остаточные реальные данные (напр. адрес).
> Слой личный/`.gitignore` — для работы это допустимо; перед передачей образца **наружу** — до-обезличить
> по `references/anonymization-procedure.md`.

## Карточка (`cards/<категория>/<slug>.md`)

Схема frontmatter:

```yaml
---
type: document_sample
created: <ГГГГ-ММ-ДД>
sample_category: contracts        # contracts | amendments | litigation | koap | gov-responses
doc_kind: "<тип и краткое описание документа>"
source_file: "<путь к исходнику>"  # провенанс
jurisdiction: РФ
language: ru                       # ru | en | bilingual
paper: counterparty                # ours | counterparty | compromise — чья бумага
sample_level: acceptable           # reference | acceptable | anti
anonymization: verified            # verified | needs_review
status: candidate                  # candidate → verified (юрист); migrated — перенесённый массив vault
tags: [document-sample, <категория>]
---
```

`paper` и `sample_level` — из опроса юриста; у мигрированных карточек могут отсутствовать.

Тело новой карточки (`skills/sample-intake/SKILL.md`):

- **«Контекст от юриста (дата)»** — ответы юриста: чья бумага, уровень, судьба, для каких
  задач, что главное; уточнения по ходу — туда же с датой. Нет ответа — `[ВОПРОС ЮРИСТУ]`;
- «Тип документа», «Структура», «Переиспользуемые приёмы»;
- **«Наблюдения агента»** — вопросы агента, не выводы; отделены от контекста юриста;
- «Технические дефекты — не воспроизводить», «Состояние обезличивания»;
- «Когда брать» (и «Не брать»).

Мигрированные карточки — в прежней форме («Тип документа», «Контекст применения»,
«Стороны», разбор блоков).

## Как используется

Скилы (`contract-drafter`, `amendment-drafter`, `procedural-document-drafter`,
`gov-response`, `playbook-builder` и др.) находят образец
здесь: сначала сводный индекс `INDEX.md` (генерируется
`python tools/sample_intake/intake.py index`, руками не править), затем **Read** карточки;
запасной путь — **Glob** (`cards/<категория>/*.md`). ⚠️ Карточки в `.gitignore` —
обычный Grep-инструмент их не видит; для полнотекстового поиска по телу — `rg
--no-ignore` через Bash. Поиск по конкретной норме — `NORMS-INDEX.md` (строится той же
командой из полей `norm_links` / `guidance_links` карточек; формат —
`references/legal-document-samples-usage.md`, «Поиск по норме»).

**Карточка ≠ текст.** Карточка — это разбор (структура, приёмы, применимость), но **не
дословный текст пунктов**. Для реального драфтинга (увидеть внутреннюю структуру больших
пунктов и адаптировать фактическую формулировку, а не сочинять с нуля) — открыть **парный
оригинал** `originals/<категория>/<slug>.md` (тот же `<slug>`). Порядок: Glob+Read карточку
(понять приёмы/применимость, выбрать) → Read парный оригинал (взять фактический текст) →
адаптировать (не копировать 1:1). Overview-карточек это не касается (у них оригинала нет).
Образец — **источник формы, не право**: структура/формулировки берутся как ориентир,
копирование 1:1 не делается, факты сверяются с первоисточником. Нет профиля/карточки
— скил честно сообщает «в профиле нет образца этого типа».

Правила использования и статусы качества — `references/legal-document-samples-usage.md`
(навигатор слоя). Обезличивание новых образцов — `references/anonymization-procedure.md`.

## Как пополнять

Есть два равноценных входа в один transform:

- положить документ в `_inbox/`: единый watcher выполнит локальное обезличивание и
  создаст task-card без запуска LLM;
- указать готовый документ в `workflow/` и попросить «добавить как образец» через
  `sample-intake`.

В обоих случаях обезличенный оригинал попадает в
`originals/<категория>/<slug>.md`; агент дочищает обезличивание, опрашивает юриста и
создаёт карточку-разбор со статусом `candidate`; `verified` присваивает только юрист.
Задачу очереди watcher исполняет `skills/sample-intake/SKILL.md`.
