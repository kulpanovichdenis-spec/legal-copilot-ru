# profile/ — пользовательский слой (overlay)

Эта папка — твой личный слой поверх базового legal-copilot. Обновление из
GitHub её НЕ трогает: здесь живут твои настройки, свои skills, заметки к
базовым skills, свои образцы и обратная связь.

Содержимое (кроме этого README и скелета `.gitkeep`) в git не попадает.

## Что внутри

- `profile.yaml`   — кто ты, где физически лежит профиль, версия базы (создаётся автоматически).
- `INDEX.md`       — генерируемый индекс: что из оверлея подключено (пересобирается при relink).
- `skills/`        — твои собственные новые skills (добавляются, базовые не трогаются).
- `overrides/`     — заметки-дополнения к базовым skills: `overrides/<имя-базового-skill>.md`.
- `templates/`     — твои образцы/шаблоны (при совпадении имени с базовым побеждают твои).
- `settings/`      — `.env`, локальный MCP-конфиг и ключи. Внешние правовые базы выбираются через `python -m tools.legal_overlay.connection_setup`; отсутствующие остаются `disabled_no_network`.
- `feedback/`      — твоя обратная связь (JSONL по месяцам).
- `knowledge/`     — локальные reusable knowledge objects по состояниям
  `candidates/`, `verified/`, `superseded/`; `human_verified` присваивается
  только отдельным подтверждённым действием юриста.

## Перенос на другую машину

Профиль можно держать на Яндекс.Диске или флешке. Команды агенту:
«перенеси профиль на D:\YandexDisk\legal-copilot-profile», «собери профиль в zip»,
«восстанови профиль из папки». Путь запоминается в файле `.profile-path` в корне репо.
