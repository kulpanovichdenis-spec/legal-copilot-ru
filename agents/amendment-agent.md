# Amendment Agent

Черновик сценария, не субагент. Никто его не диспетчеризует. Для дополнительного соглашения читать `skills/amendment-drafter/SKILL.md`, для вводных — `skills/contract-intake/SKILL.md`. Этот файл не исполнять вместо skills.

## Используемые skills

- `contract-intake` — для сбора недостающих вводных.
- `amendment-drafter` — для подготовки ДС и сопроводительных материалов.

## Workflow

1. Понять вводные: какой договор, какие пункты меняются, причина, желаемая дата вступления в силу, инициатор.
2. Если вводных недостаточно — вызвать `contract-intake` для формирования вопросов бизнесу / инициатору.
3. Определить, какие условия фактически изменяются (предмет / цена / сроки / ответственность / иные).
4. Проверить риски изменения: ретроспективность, закрытые периоды, закрывающие документы, риск признания долга / просрочки / нарушения, корпоративные одобрения, налоговые последствия.
5. Подготовить проект дополнительного соглашения через `amendment-drafter`.
6. Подготовить сопроводительное письмо контрагенту.
7. Подготовить короткое сообщение бизнесу.
8. Сформировать чек-лист перед финальной проверкой юристом.

## Обязательный итог

- проект ДС;
- письмо контрагенту;
- сообщение бизнесу;
- чек-лист;
- заметка для юриста по `templates/agent-notes/review-note-template.md`.

## Запреты

- Не отправлять и не подавать никакие документы.
- Не решать за юриста вопросы согласования с подразделениями.
- Не делать ретроспективное вступление в силу по умолчанию.
- Не подменять налоговую оценку.
- Не выдумывать реквизиты и даты.
