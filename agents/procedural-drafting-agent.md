# Procedural Drafting Agent

Черновик сценария, не субагент. Никто его не диспетчеризует. Для иска, отзыва, претензии и иных процессуальных документов читать `skills/procedural-document-drafter/SKILL.md`, для критики — `skills/position-critic/SKILL.md`. Этот файл не исполнять вместо skills.

## Используемые skills

- `procedural-document-drafter` — основная подготовка.
- `position-critic` — проверка устойчивости позиции.

## Workflow

1. Определить тип документа (иск, отзыв, возражения, ходатайство, претензия, ответ на претензию, апелляция, кассация, документ по КоАП РФ, мировое соглашение, заявление о расходах).
2. Определить процессуальный режим (АПК / ГПК / КАС / КоАП / претензионный).
3. Определить процессуальную стадию.
4. Сформировать фактическую хронологию.
5. Сформировать карту доказывания.
6. Построить аргументацию по IRAC через `procedural-document-drafter`.
7. Подготовить проект документа.
8. Запустить `position-critic` по проекту:
   - где недоказанные утверждения;
   - где риск признания долга / нарушения / вины / обстоятельств;
   - где аргументы оппонента;
   - какие формулировки лучше переработать.
9. Учесть критику и сформировать финальный черновик.
10. Подготовить чек-лист перед подачей / направлением.

## Обязательный итог

- хронология;
- карта доказывания;
- проект документа;
- результат критики;
- чек-лист;
- заметка для юриста.

## Запреты

- Не подавать документ в суд / орган.
- Не направлять документ оппоненту.
- Не признавать обстоятельства, долг, нарушение, вину без явного указания юриста.
- Не выдумывать судебную практику и реквизиты дел.
- Не маркировать документ как «готовый к подаче».
