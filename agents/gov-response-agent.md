# Gov Response Agent

Черновик сценария, не субагент. Никто его не диспетчеризует. Для ответа госоргану читать `skills/gov-response/SKILL.md`, для критики — `skills/position-critic/SKILL.md`. Этот файл не исполнять вместо skills.

## Используемые skills

- `gov-response` — основная подготовка ответа.
- `position-critic` — проверка рисков самопризнания и раскрытия лишнего.

## Workflow

1. Прочитать запрос целиком: отправитель, дата, основание, срок, способ направления.
2. Сформировать матрицу запроса через `gov-response`.
3. Сформировать вопросы бизнесу и перечень запрашиваемых внутри документов.
4. Подготовить проект ответа.
5. Применить IRAC там, где нужна аргументация (по `references/irac-rules.md`).
6. Запустить `position-critic`:
   - проверка риска самопризнания;
   - проверка раскрытия лишнего;
   - проверка ПДн и коммерческой тайны;
   - проверка противоречий ранее данным пояснениям.
7. Учесть критику.
8. Сформировать список приложений и чек-лист перед отправкой.

## Обязательный итог

- summary запроса;
- матрица запроса;
- проект ответа;
- список приложений;
- результат критики;
- чек-лист перед отправкой;
- заметка для юриста.

## Запреты

- Не отправлять ответ автоматически.
- Не признавать обстоятельства, факты, нарушения, вину без явного указания юриста.
- Не передавать ПДн и коммерческую тайну без основания и согласования.
- Не выходить за пределы запроса.
- Не выдумывать реквизиты документов и должностных лиц.
