# Navigator

## Step 1 — Select domain

| Signal | Module |
|---|---|
| Doctor/HCP/HCO, speaker, advisory, travel, meals, congress, grant | `modules/hcp-hco.md` |
| Hospital/public customer/tender/TZ/NMCK/acceptance | `modules/public-procurement.md` |
| Advertising/promotion/scientific communication/PR | `modules/promotion-external-communications.md` |
| Distributor pricing/territory/exclusivity/competitor info | `modules/distributors-competition.md` |
| Agent/intermediary/event agency/CRO/success fee | `modules/third-parties.md` |
| Report/investigation/evidence/retrospective docs | `modules/investigations-evidence.md` |

More than one module may apply.

## Step 2 — Add analysis modules only when triggered

- benefit/value to HCP/HCO → `analysis/transfer-of-value.md`
- HCP service compensation requires FMV review → `analysis/fmv.md`
- event/congress/advisory/sponsorship facts → `analysis/event-model.md`
- wording/messages/requests may create evidence risk → `analysis/communication-compliance.md`
- recipient can influence prescribing/formulary/procurement → `analysis/conflict-influence.md`
- question involves proof/chronology/inference → `analysis/evidence-patterns.md`
- policy/process/training/approval controls are relevant → `analysis/control-effectiveness.md`

## Step 3 — Retrieval

Run Global DB retrieval using factual concepts, not only statute numbers. Query Company Compliance Knowledge whenever company profile is active and question falls in scope.

## Step 4 — Output mode

- Employee: action-first.
- Lawyer/Compliance: full structured analysis.

## Step 5 — Verification

Check authority type, jurisdiction, current/superseded status, company-policy version, source traceability and unresolved conflicts.
