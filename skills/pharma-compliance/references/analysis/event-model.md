# Analysis — Event Model

Use one event object for speaker programs, congresses, advisory boards, sponsorship and related HCP/HCO events.

Capture: event type, organizer, scientific/educational purpose, audience, location, duration, HCP roles, company role, all value components, decision links, evidence of actual performance and approvals.

The goal is to prevent a misleading single-label analysis such as “conference support”. A legitimate scientific event can still contain a problematic benefit component; conversely, reasonable travel/meals can be legitimate when ancillary to the real professional purpose.
