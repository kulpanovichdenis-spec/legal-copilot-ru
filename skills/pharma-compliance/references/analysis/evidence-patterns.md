# Analysis — Evidence Patterns

## Evidence classes

Email/messenger, phone/audio, document metadata, chronology, bank transactions, expense records, contracts/invoices, tender documents, witness testimony, files on devices, identical/retrospective documents.

## Model

`Behaviour → Evidence → Authority inference → Court/regulator treatment → Safe/control implication`.

## Chronology

Chronology is a first-class object. Examples: selected supplier before competing quotations; service fee after favorable decision; approval created after payment; repeated engagement following sales change.

Do not treat an evidentiary pattern as conclusive without context and authority treatment.
