# Analysis — Communication Compliance

## Goal

Recognize risky requests/wording and provide a compliant next action without creating a simplistic forbidden-word list.

## Analyse

- semantic meaning;
- sender/recipient roles;
- procurement/decision stage;
- requested action;
- benefit/expectation;
- surrounding chronology;
- whether lawful context is documented.

## Output

When communication is risky, provide:

1. action not to take;
2. lawful alternative;
3. suggested neutral response if useful;
4. what to preserve;
5. escalation trigger.

Never recommend deletion, concealment or fabrication of communications.
