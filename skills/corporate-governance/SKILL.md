# Corporate Governance — компетенция

Архитектурный паттерн: router с одним сценарием («компетенция»), Medium freedom. Детерминированное ядро — `tools/corporate_governance/governance.py` (`competence`, `tag-decisions`, `validate-catalog`, `decisions-review`; описание — `tools/corporate_governance/README.md`); каталог решений ООО — `references/corporate-decisions/llc.yaml`; методика и политика верификации — `references/corporate-governance-method.md`. Здесь они не дублируются.

## Назначение

Ответ на вопрос «кто в этом обществе решает X» по профилю общества, построенному `skills/charter-review/SKILL.md`, для любого ООО с профилем в `profile/knowledge/corporate/entities/`. Без профиля сценарий не работает: предложить юристу разбор устава. Матрица компетенции из отчёта разбора устава (`report --view competence`) показывает, что написано в уставе; этот сценарий отвечает на конкретный вопрос с нормой закона по умолчанию, связанными режимами и статусом.

## Сценарий «компетенция»

1. Определить общество (`slug`); не опознаётся — спросить. Сопоставить вопрос с позициями каталога по `title` и `synonyms`, включая связанные: для сделки (заём, кредит, поручительство, залог) — также `major_transaction` и `interested_party_transaction`. Позиции нет — сказать юристу «позиции в каталоге нет, ответ не по профилю общества» и ответить по общему циклу `CLAUDE.md` с `[ПРОВЕРИТЬ НОРМУ]`; ближайшую позицию молча не подставлять.
2. Из Bash: `python tools/corporate_governance/governance.py competence --slug <slug> --decision <id> [--decision <id2>]`. JSON — единственный источник оснований для ответа.
3. По статусу:
   - `BLOCKED` — по существу не отвечать; назвать причины из `reasons` и что нужно.
   - `NEEDS_FRESHNESS` — по каждой норме из `stale_norms` выполнить Legal Freshness Check по методике (`route_norm_verification(jurisdiction="RU", probe=true)`, только `usable_now: true`; поведение без пригодного маршрута — там же). Для правила — `set-freshness` (`--checked-source`, если текст открыт не через pravo.gov.ru), затем повторить `competence`. Позицию каталога агент не правит: ответ опирается на только что открытую статью, юристу одной строкой — редакция та же или изменилась и нужно ли обновить `verified_at` каталога.
   - `NEEDS_REVIEW` — ответить, пометив кандидатов, конфликты и правила без привязки (`untagged_in_topics`: разметка не завершена, вывод о молчании устава не делать); решение за юристом.
   - `ASSUMPTION` — назвать норму закона по умолчанию из `catalog` и открытые допущения; при `charter_silent` — «привязанных правил нет».
   - `RESOLVED` — ответить.
4. Истолковать условия и исключения в `value` правил («кроме», «если», «за исключением») применительно к фактам вопроса; не хватает факта (является ли контрагент аффилированным лицом) — условный вывод и вопрос юристу.

## Ответ юристу

Первая фраза — орган, большинство, форма подтверждения; условие или исключение, меняющее ответ, — в той же фразе. Затем основания по уставу (пункт, страница, `R-…`, статус — по каждому правилу из `charter_rules`), основания по закону (статья, редакция, дата проверки), оговорки (`notes`, допущения, маркеры) и что нужно от юриста. По умолчанию в чате; `.docx` — по просьбе юриста (`workflow/<дата> …/`, `references/document-formatting.md`).

## Принципы

1. Основания — только из JSON `competence` по этому обществу; правила другого общества группы не используются.
2. Каждое правило из `charter_rules` есть в ответе, включая исключения и кандидатов.
3. Статус ответа не мягче статуса `competence`.
4. Норма закона — после живой проверки не старше 30 дней или с маркером; отметка проверки в профиле старше порога основанием не служит.
5. Без абсолютов («всегда», «однозначно») для тезисов без подтверждённого правила или проверенной нормы.
6. Всё — черновик; `confirm`, `tag-decisions` и содержательные правки каталога — только по решению юриста (`confirm` — с его ФИО).

## Границы

Не проверяет действительность принятого решения, не готовит решения и протоколы, не ведёт сроки — следующие циклы подсистемы 2 (раздел 10 дизайна). Только ООО по праву РФ: АО, иностранные общества и иностранные компании группы не поддерживаются — сказать юристу, ответа по каталогу не давать.
