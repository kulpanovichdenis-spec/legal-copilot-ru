# ФЗ-184 «О техническом регулировании»

Архитектурный паттерн: domain-intelligence. Карта норм, системные выводы, алгоритм письма органа и типовые ошибки — один источник: `references/fz184-technical-regulation.md`. Этот skill карту не дублирует.

## Алгоритм

1. Открыть `references/fz184-technical-regulation.md` и читать только разделы, которые сработали по вопросу.
2. Перед сроком, статьёй или компетенцией органа вызвать `route_norm_verification(jurisdiction="RU", probe=true)` и использовать только маршрут `usable_now: true`. Нет маршрута — `[ПРОВЕРИТЬ НОРМУ]`.
3. Ответ органу вне суда готовит `gov-response`. Судебное обжалование и иск готовит `procedural-document-drafter`.
