# Европейский союз (EU) — адаптер проверки контрагента (стаб)

Назначение: тонкий country-адаптер для контрагента, зарегистрированного в одной из стран ЕС, выбираемый country-router'ом `SKILL.md` (`skills/counterparty-verification/SKILL.md`, шаг COUNTRY ROUTER). **Глубокая автоматизация для этой юрисдикции не реализована** (§30 ТЗ — первая версия skill'а покрывает глубоко только РФ, `skills/counterparty-verification/countries/RU.md`). Проверка по этому адаптеру — ручная, по указанным официальным источникам.

Общая методология, risk-engine и оформление отчёта — не здесь: `skills/counterparty-verification/references/methodology.md`, `skills/counterparty-verification/references/risk-rules.md`, `skills/counterparty-verification/references/report-rules.md`. Санкционная проверка — `skills/counterparty-verification/references/sanctions-check.md` (там же — EU консолидированный список, применимый к любому контрагенту независимо от страны).

## 1. Официальные реестры

Единого общеевропейского реестра ЮЛ с полной карточкой нет — базовая связка между странами обеспечивается BRIS, но содержательная информация — в национальном реестре конкретной страны.

| Источник | Даёт | Ограничение |
|---|---|---|
| **BRIS / European e-Justice Portal** (Business Registers Interconnection System, портал `e-justice.europa.eu`) | точку входа для поиска компании по стране регистрации и ссылку на национальный реестр; базовые сведения (наименование, регистрационный номер, статус) | не заменяет национальный реестр по глубине сведений — используется как навигационная точка входа, а не окончательный источник |
| **Национальный business register** страны регистрации (например, Handelsregister — Германия, Registre du commerce et des sociétés — Франция, KVK — Нидерланды, и т. д. — свой у каждой страны ЕС) | полная официальная карточка: статус, представители, учредительные документы, иногда — финансовая отчётность | формат, язык и объём открытых (бесплатных) сведений различаются по странам; часть сведений в части стран — платно |
| **EU insolvency registers** (национальные регистры несостоятельности, часть из них связана через `e-justice.europa.eu/insolvency`) | сведения о процедурах банкротства/несостоятельности | покрытие по странам неполное — не все страны интегрированы в общий поиск в равной степени |
| **EU sanctions** — консолидированный санкционный список (см. `skills/counterparty-verification/references/sanctions-check.md`, раздел 1) | санкционный статус | применяется независимо от того, что глубокая автоматизация реестра для ЕС отсутствует |
| Национальные дополнительные источники (по стране) | судебные реестры, отраслевые лицензии и т. п. | определяются по стране конкретного контрагента отдельно |

## 2. Что извлечь

- юридическое наименование по национальному реестру (включая организационно-правовую форму страны — GmbH, SARL, B.V. и т. п.);
- регистрационный номер в национальном реестре и страна/land/провинция регистрации (для федеративных государств, например Германии — конкретный Amtsgericht);
- статус регистрации (действующая / в процессе ликвидации / исключена);
- представители (директора/legal representatives) по данным реестра — для последующей сверки с лицом, фактически подписывающим договор;
- зарегистрированный адрес (registered office);
- при доступности — сведения о процедуре несостоятельности (EU insolvency registers).

## 3. Специфические red flags

- статус, отличный от действующего (ликвидация, исключение из реестра);
- сведения о процедуре несостоятельности в национальном insolvency register;
- несовпадение representative по реестру с фактическим подписантом договора;
- совпадение (даже частичное) с записью в EU sanctions list — обрабатывается по `skills/counterparty-verification/references/sanctions-check.md`, статус `POTENTIAL MATCH / MANUAL REVIEW REQUIRED` при неподтверждённом совпадении.

Red flag не равнозначен автоматическому отказу — оценивается по `skills/counterparty-verification/references/methodology.md` и `skills/counterparty-verification/references/risk-rules.md`.

## 4. Границы / ограничения

- **Глубокая автоматизация не реализована.** Определение страны, переход через BRIS/e-Justice к национальному реестру и извлечение карточки — ручной шаг агента, не детерминированный скрипт.
- **Фрагментация по странам.** 27 национальных систем с разным языком, форматом и уровнем бесплатного доступа — единой методики извлечения нет; для каждой конкретной страны состав доступных полей и их достоверность нужно оценивать заново, не переносить практику одной страны ЕС на другую.
- **Платный доступ.** В ряде стран полная выписка или отдельные документы (учредительные, финансовая отчётность) доступны только платно — при отсутствии доступа это отмечается как ограничение, официальный источник не подменяется агрегатором молча.
- **Insolvency registers — неполное покрытие.** Отсутствие записи в едином поиске `e-justice.europa.eu/insolvency` не равнозначно отсутствию процедуры несостоятельности, если страна контрагента не полностью интегрирована в эту систему — при значимости сделки может потребоваться прямая проверка национального insolvency register.
- Судебная практика по контрагенту (гражданские/коммерческие споры) в этой версии skill'а не автоматизирована — доступность и формат судебных данных различаются по странам ЕС значительно сильнее, чем в РФ (единой КАД-аналогии на уровне ЕС нет).
- Санкционная проверка — по `skills/counterparty-verification/references/sanctions-check.md`, полный минимальный набор перечней (не только EU-список).
- Все ограничения — в раздел «Ограничения проверки» итогового DOCX (`skills/counterparty-verification/references/report-rules.md`).
