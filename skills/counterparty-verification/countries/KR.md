# Республика Корея (KR) — адаптер проверки контрагента (стаб)

Назначение: тонкий country-адаптер для контрагента, зарегистрированного в Республике Корея, выбираемый country-router'ом `SKILL.md` (`skills/counterparty-verification/SKILL.md`, шаг COUNTRY ROUTER). **Глубокая автоматизация для этой юрисдикции не реализована** (§30 ТЗ — первая версия skill'а покрывает глубоко только РФ, `skills/counterparty-verification/countries/RU.md`). Проверка по этому адаптеру — ручная, по указанным официальным источникам.

Общая методология, risk-engine и оформление отчёта — не здесь: `skills/counterparty-verification/references/methodology.md`, `skills/counterparty-verification/references/risk-rules.md`, `skills/counterparty-verification/references/report-rules.md`. Санкционная проверка — `skills/counterparty-verification/references/sanctions-check.md`.

## 1. Официальные реестры

| Источник | Даёт | Ограничение |
|---|---|---|
| **Официальные корейские регистрационные источники** — прежде всего корпоративный реестр (법인등기부등본 — выписка из корпоративного реестра, ведётся судебной регистрационной системой Кореи) | официальная регистрационная карточка: наименование, регистрационный номер, статус, представитель, адрес | доступ к полной выписке в ряде случаев требует официального запроса/оплаты через корейскую систему электронной регистрации (인터넷등기소); англоязычный интерфейс ограничен |
| **DART** (Data Analysis, Retrieval and Transfer System, Financial Supervisory Service, `dart.fss.or.kr`) | финансовая отчётность и раскрытие информации — **только для компаний, обязанных раскрывать информацию** (публичные компании и определённые крупные частные компании по корейскому законодательству о внешнем аудите) | **не универсальный аналог ЕГРЮЛ** — отсутствие контрагента в DART не является нарушением и не признак проблемы, если контрагент не подпадает под обязательное раскрытие; DART не подтверждает и не опровергает базовый факт регистрации/статус компании |

## 2. Что извлечь

Из корпоративного реестра (法人登記簿謄本 / 법인등기부등본) или предоставленной контрагентом официальной выписки:

- юридическое наименование на корейском языке и, если применимо, официальное английское наименование;
- регистрационный номер юридического лица (사업자등록번호 — номер регистрации налогоплательщика, либо 법인등록번호 — номер корпоративной регистрации; это разные номера, оба уточняются, если доступны);
- статус (действующая / ликвидация / реорганизация);
- представитель (代表理事 / 대표이사 — аналог ЕИО) — для последующей сверки с фактическим подписантом;
- зарегистрированный адрес.

Дополнительно, если контрагент раскрывается в DART, — финансовая отчётность и существенные корпоративные события за раскрываемые периоды.

## 3. Специфические red flags

- статус, отличный от действующего (ликвидация, реорганизация в неблагоприятном контексте);
- несовпадение представителя (代表理事) по официальной выписке с лицом, фактически подписывающим договор;
- для компаний, раскрывающихся в DART, — существенные негативные события в раскрытии (аудиторские оговорки, going concern doubt, делистинг), если применимо.

Red flag не равнозначен автоматическому отказу — оценивается по `skills/counterparty-verification/references/methodology.md` и `skills/counterparty-verification/references/risk-rules.md`.

## 4. Границы / ограничения

- **Глубокая автоматизация не реализована.** Обращение к корейскому корпоративному реестру и извлечение карточки — ручной шаг агента, не детерминированный скрипт.
- **DART не заменяет базовую регистровую проверку.** DART покрывает только раскрывающие информацию компании — для типового частного корейского контрагента базовая проверка статуса ведётся через корпоративный реестр, а не через DART; смешивать эти два источника как взаимозаменяемые — ошибка.
- **Языковой барьер.** Основные источники — на корейском языке; перевод ключевых полей должен быть либо официальным, либо явно помечен как рабочий перевод агента, требующий сверки юристом.
- **Доступность.** Полная официальная выписка из корпоративного реестра в ряде случаев доступна только через платный запрос в корейской системе электронной регистрации — при отсутствии доступа это отмечается как ограничение.
- Судебная практика, банкротство/несостоятельность (회생·파산), исполнительные производства по контрагенту из Кореи — в этой версии skill'а не автоматизированы; фиксируются как ограничение проверки, а не как «не выявлено».
- Санкционная проверка — по `skills/counterparty-verification/references/sanctions-check.md`, полный минимальный набор перечней.
- Все ограничения — в раздел «Ограничения проверки» итогового DOCX (`skills/counterparty-verification/references/report-rules.md`).
