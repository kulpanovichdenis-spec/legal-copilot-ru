# Разрешение routing-фактов

Цель — получить только те сведения, которые нужны для определения material scope, применимости coverage obligations и структуры сделки. Не проходи вопросник по порядку ради формы. Сначала используй уже подтвержденный project state и доступные документы. Задавай человеку только вопросы, которые остаются unresolved и реально меняют routing/coverage/transaction structure. Не блокируй независимую работу из-за неизвестного поля, если оно влияет только на отдельную ветку. Любой вывод из документа до human gate помечай как proposed. Человекочитаемые формулировки — на русском.
