# Consistency validation

Запускай эту capability, когда structured state может содержать alias, conflict, stale value, outlier или разные current states. Сохраняй raw values. Не заменяй minority value на majority. Не исправляй юридически значимый факт без evidence/human resolution. Создавай только те review items, которые могут изменить material state или downstream use.
