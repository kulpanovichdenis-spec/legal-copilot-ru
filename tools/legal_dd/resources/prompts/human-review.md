# Human review

Покажи минимальный набор material items, требующих human accountability. Для каждого — proposed value/conclusion, source, exact locator, quote, linked obligation и downstream effect. Допускай batch review, если это не снижает проверяемость. При modify/reject сохраняй прежнее agent value в audit, пересчитывай только зависимые nodes и переводь затронутые confirmed conclusions в reconfirmation_required.
