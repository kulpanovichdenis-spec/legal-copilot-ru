# Purpose-driven extraction

Извлекай факты, необходимые для разрешения активных Evidence Requirements / coverage obligations. Не заполняй всю схему только потому, что поля существуют. Для каждого material answered поля сохраняй дословную короткую цитату и exact locator. Используй not_present / unclear / needs_review / conflict_detected, когда факт не установлен надежно. Не делай окончательных юридических выводов. Цитата сохраняется на языке оригинала, человекочитаемое пояснение — на русском.
