# State Duty Calculator — контракт вход/выход

Модель классифицирует спор (regime, claim_type, категория, льготы) — скрипт считает сумму. Модель никогда не делает арифметику госпошлины сама (CLAUDE.md/ТЗ §116).

**Статус данных (2026-09-16).** Все ставки в `rules/state_duty_rates.yaml` и льготы в `rules/state_duty_exemptions.yaml` сверены **дословно** по официальному тексту НК РФ, полученному напрямую с `pravo.gov.ru` (nd=102067058) по протоколу `references/pravo-gov-ru-search-protocol.md` — не через WebSearch/агрегаторы. Первая версия (собранная через WebSearch по Гарант/КонсультантПлюс) содержала ошибки на нескольких пунктах — см. комментарии в начале обоих YAML-файлов и историю коммитов; это подтверждает правило проекта [[npa-lookup-official-tools-not-web]]: агрегированный ответ поисковика по норме — не то же самое, что дословный текст, и никогда не выдаётся как `PAYABLE`.

## CLI

```
python -m tools.court_jurisdiction.state_duty calculate \
  --regime GPK|APK \
  --claim-type property_assessable|fixed|writ_of_payment|other \
  [--fixed-category CODE] \
  [--claimant-type individual|organization|debtor_self] \
  [--amount N] \
  [--consumer] \
  [--exemption CODE ...] \
  [--calculation-date YYYY-MM-DD] \
  [--claims-file claims.json]

python -m tools.court_jurisdiction.state_duty list-rules --regime GPK|APK
python -m tools.court_jurisdiction.state_duty selftest
```

`--regime` — процессуальный режим, определённый нормативным resolver-ом (`GPK` покрывает и мировых судей, и КАС — обе системы используют ставки ст. 333.19 НК РФ, см. «Известные пробелы» про КАС-специфику).

`--claim-type`:
- `property_assessable` — цена иска известна и подлежит оценке (пп.1 п.1 ст.333.19/333.21) — прогрессивная шкала.
- `fixed` — конкретная категория с фиксированной суммой из перечня `fixed_rates` (см. `--fixed-category` ниже); требуется `--claimant-type individual|organization` (кроме категорий с `flat`-ставкой, где различия физ/юрлиц нет).
- `writ_of_payment` — заявление о вынесении судебного приказа: 50% от пошлины по имущественному требованию (нужен `--amount` — сумма самого требования), с floor 8000 руб. для АПК.
- `other` — категория, не покрытая ни одной из закодированных таблиц; всегда `MANUAL_REVIEW_REQUIRED` без угаданной суммы.

`--fixed-category` (полный список — `python ... list-rules --regime X`, поле `fixed_rates[].categories`):

| Категория | ГПК (физ/юр) | АПК (физ/юр) | Основание |
|---|---|---|---|
| `non_property` | 3000 / 20000 | 15000 / 50000 | иск неимущ. характера / имущ. без оценки |
| `act_challenge_normative` | 4000 / 20000 | 10000 / 60000 | оспаривание нормативных актов |
| `act_challenge_nonnormative` | 3000 / 15000 | 10000 / 50000 | оспаривание ненормативного акта/решения/действия(бездействия) |
| `divorce` | flat 5000 | — | расторжение брака (только ГПК) |
| `special_proceedings` | flat 3000 | — | дела особого производства (только ГПК) |
| `legal_succession` | 2000 / 15000 | 5000 / 25000 | правопреемство (кроме универсального) |
| `appeal` | 3000 / 15000 | 10000 / 30000 | апелляционная/частная жалоба, кассация на приказ |
| `cassation` | 5000 / 20000 | 20000 / 50000 | кассационная жалоба |
| `cassation_supreme` | 7000 / 25000 | 30000 / 80000 | кассационная/надзорная жалоба в ВС РФ |
| `reasonable_time_compensation` | 300 / 6000 | 300 / 6000 | компенсация за нарушение разумного срока |
| `bankruptcy_petition` | — | 10000 / 100000 (0 при `--claimant-type debtor_self`) | заявление о банкротстве (только АПК) |
| `establish_fact` | — | flat 30000 | установление факта, имеющего юр. значение (только АПК) |

`claims.json` для нескольких требований в одном заявлении:

```json
[
  {"type": "property_assessable", "amount": 400000},
  {"type": "property_assessable", "amount": 300000},
  {"type": "fixed", "fixed_category": "non_property", "claimant_type": "organization"}
]
```

Имущественные требования суммируются в одну цену иска (дословно подтверждено для АПК — ст.333.22 п.1 пп.2; для ГПК — общий процессуальный принцип, ст.333.20 НК РФ отдельно это не оговаривает). Неимущественные/fixed/other считаются отдельно по каждому требованию, сверх суммы по имущественным.

## Статусы результата

| status | значение |
|---|---|
| `PAYABLE` | сумма посчитана по правилу с `confidence: verified_fulltext` |
| `EXEMPT` | сработала полная льгота — `amount: 0` |
| `PARTIALLY_EXEMPT` | льгота с порогом — пошлина посчитана только с суммы превышения порога |
| `CANNOT_CALCULATE` | не хватает данных (`claim_amount`/`claimant_type`/`fixed_category`) или нет версии правила на указанную дату/категорию |
| `MANUAL_REVIEW_REQUIRED` | `claim_type=other` (категория не входит ни в одну оцифрованную таблицу), либо льгота по неизвестному коду отдельно помечена `UNKNOWN_CODE` внутри `exemption_check` (сам расчёт при этом продолжается на общих основаниях, льгота не подставляется молча) |

**Сумма к уплате.** `amount` — арифметика по ставке, с копейками. В документ и платёжку ставится `payable_rub` — сумма в полных рублях, **любые копейки округляются в большую сторону** (решение юриста 2026-10-16: переплата до рубля исключает недоплату; Минфин в письме от 02.11.2023 № 03-02-07/104841 допускает арифметическое округление, но для подачи выбран консервативный вариант), основание в `rounding_basis`: п. 6 ст. 52 НК РФ в ред. 389-ФЗ (сверено на pravo.gov.ru 2026-10-16). Постановление Пленума ВАС РФ от 11.07.2014 № 46, на которое ссылались раньше, утратило силу; на него не ссылаться. Если сумма получена вручную (например, 50 % по пп. 9 п. 1 ст. 333.21 НК РФ для заявления в деле о банкротстве), округлять так же — `to_full_rubles()`.

## Известные пробелы (актуально на 2026-09-16)

- **КАС не имеет отдельной таблицы.** Административные иски по КАС РФ используют ставки ст. 333.19 НК РФ (общий блок для ВС РФ/СОЮ/мировых судей включает и КАС-категории напрямую в тексте статьи — «административного искового заявления», «административного истца» встречаются в тех же подпунктах) — вызывать с `--regime GPK`.
- **Льготы ст. 333.36/333.37 закодированы не полностью.** Ст. 333.36 п.1 содержит 26 подпунктов (последнее дополнение — пп.26 от 20.02.2026 № 40-ФЗ, льготы участникам СВО и связанным категориям пп.24-26); закодированы самые частые в in-house практике (трудовые, алименты, вред здоровью/от преступления, потребители, инвалиды, ветераны, пенсионеры, общественные организации инвалидов, госорганы). Незакодированный код → `UNKNOWN_CODE` в `exemption_check`, не трактуется как «льготы нет» — юрист/агент сверяет напрямую.
- **Обособленные банкротные споры (АПК пп.9 п.1 ст.333.21)** — калькулятор знает саму формулу (50% от базы пп.8), но не автоматизирует выбор *какая именно* сумма-база (10000/100000) соответствует конкретному виду обособленного спора — «исходя из существа заявленных требований» оценивает юрист (см. карточку `bankruptcy`).
- **Основание для дальнейшего пополнения** — по мере того как в практике встретится конкретный неоцифрованный подпункт, добавлять новую запись в `fixed_rates`/`exemptions` со сверкой через тот же протокол pravo.gov.ru, не по памяти.
